# 舆情（新闻情绪）

看板右列的**重点舆情**回答一个问题：**刚刚发生的这条消息，对加密市场偏多、偏空，还是没有明确方向？**

它只处理文本事件——监管文件、交易所公告、行业新闻——不重复经济日历、资金费率、稳定币或行情面板已经给出的数字。

## 看什么

每条舆情包含：

```text
来源 + 发布时间 + 标题
方向：偏多 / 偏空 / 中性 / 分歧
强度：1–5（弱 / 中 / 强）
置信度：0–100%
证据引文
```

- **方向**是消息对价格的潜在影响，不是作者情绪；
- **强度**是方向性冲击的强弱，中性消息通常强度很低；
- **置信度**是模型对这次判断的确定程度；
- **中性**表示没有明确方向，不等于“无关”。

模型为主、规则兜底。模型不可用时，界面会标明判断来自规则，不会把“没跑模型”伪装成中性。

## 哪些消息不会出现

维护窗口、API/系统升级、只读公告、交易时间调整等**中性且低强度的例行通知**不会进入重点舆情。它们对交易所用户可能有用，但不构成价格方向信号；仍可在原始情报流和来源中查看。

## 卡片与抽屉

卡片默认显示 **8 条**，按发布时间倒序；滚动到底会再取 8 条。

点「查看全部舆情」打开抽屉：

- 时间：`1h` / `4h` / `24h` / `7d` / `全部`；
- 方向、来源、对象筛选；
- 中性筛选：「带中性 / 不带中性」；
- 左侧列表、右侧详情；详情含证据引文、原文正文和翻译切换。

## 数据什么时候更新

新闻源按采集预设运行：

| 来源 | 默认间隔 |
| --- | --- |
| CoinDesk RSS | 15 分钟 |
| SEC RSS | 15 分钟 |
| Binance Announcements | 30 分钟 |
| OKX Latest Announcements | 30 分钟 |

新条目进入后会立即触发正文抓取和情绪判断；应用启动时还会做一次补偿。界面本身不轮询，只在打开、刷新或切换筛选时查询。

SEC 可能连续多天没有新条目；OKX 只对交易更新、API、充提三类公告做情绪判断，因此某些时间段列表里只有 CoinDesk 和 Binance 是正常的。

## 翻译

翻译只用于**当前应用显示语言**：

- 中文界面：标题在开启自动翻译时自动翻；正文只在手动点击「翻译正文」或右键「翻译此条」时翻；
- 英文界面：不显示翻译按钮、状态或设置；
- 译文按 `条目 + 正文哈希 + 目标语言` 缓存，同一条只翻一次；正文变化后只失效这一条；
- 批量翻译最多 5 条并发，等待中的条目会显示状态，可取消剩余队列。

## 从一条新闻开始问 Agent

点击卡片或抽屉里的某条新闻，会把该条设为 Agent 的锁定上下文。打开分析对话时，Agent 顶部会显示「选中舆情 · 标题」，并在提问时带上来源、时间、方向、强度和正文，不需要你重新描述“我在说哪条新闻”。

## 边界

- 只覆盖已配置的四个文本源，不做社交/KOL、话题聚类或跨源同题合并；
- 每条只有方向判断，没有单条新闻的完整“AI 解读”；
- 不输出交易建议、仓位或价格预测；
- 所有数据与译文保存在本机，翻译和模型调用使用你配置的供应商。
