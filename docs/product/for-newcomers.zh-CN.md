# 给还在学这个市场的人

推文你读过，名词你都认识——资金费率、流动性、ETF 流入——但真让你开口解释"昨天为什么跌"，还是说不清。
这通常不是知识不够，是结构不对：你拿到的都是结论，中间的机器被跳过了。

MacroBay 把那台机器打开给你看。

![看板：数字旁边有白话解释，AI 结论带着成立条件](../assets/screenshots/dashboard-window-en.png)

## 在这里，"看懂"长什么样

你拿到的不是一句判决，而是一条链：

1. **读数**——资金费率是负的；
2. **它意味着什么**——加杠杆的多头在付钱维持仓位；
3. **它推出什么**——拥挤在退潮，但前提是费率一直为负；
4. **什么会推翻它**——价格横住而费率转正。

看上几条，你会开始预判下一块面板该说什么。那一刻，行情就不再是一堆魔法数字。

## 它会反复讲给你听的五件事

| 信号 | 它其实在说什么 |
| --- | --- |
| 永续资金费率 | 杠杆的价格。为正表示多头付给空头，也就是多头拥挤。 |
| 稳定币供给 | 场内的"干火药"。供给缩水意味着流动性在离场，而不只是换仓。 |
| ETF 流向 | 传统资金在加还是在撤，跟链上资金是两回事。 |
| 美元指数（DXY） | 全球风险偏好。美元走强，通常对加密是逆风。 |
| 宏观数据 | 所有风险资产的贴现率，加密也在里面。 |

这些在看板上都挨着数字放了一句话解释，你不需要一边看行情一边去搜术语。

## 第一周可以这么用

- **第 1 天**——打开看板，读完 AI 结论，然后点开一个数字，看它的来源和观测时间。整个产品就是围绕这个
  习惯做的。
- **第 2 天**——问智能体：*什么情况下这个结论会失效？* 读条件，别只读结论。
- **第 3 天**——挑一块面板（资金费率或稳定币），连续看三天，注意它和价格不一致的那天。
- **第 4 天**——问一个你自以为已经知道答案的问题，看它有没有给出处，还是因为缺证据而含糊其辞。
- **第 5 天**——打开宏观日历，挑一条数据，看实际值和前值，再回看市场当时怎么反应。

一周下来，你手里会有一张"水管图"，而不是二十个指标。

## 它不会做的事

- **不会告诉你买什么。** 它给的是推理，不是信号，也不构成任何投资建议。
- **不会哄你。** 数据缺失时面板会直说，而不是显示一个 0。空的意思是"没接上"，不是"中性"。
- **不是课程。** 没有大纲，你是在读真实市场上的真实结论。
- **需要你自己配置。** 要准备模型 API Key、选择数据源，因为它跑在本地、数据留在你自己的机器上。
  它不是一个点开就能用的网页。
