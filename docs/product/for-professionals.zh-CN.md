# 给靠这个吃饭的人

你已经有框架了。资金费率、稳定币供给、美元指数对一本加密账意味着什么，你清楚。你缺的不是观点，
是一个地方——把每天早上要看的四件事摆在一起，而且结论经得起别人问一句"你怎么知道"。

MacroBay 解决的是第二个问题。

![看板与分析智能体读的是同一批证据](../assets/screenshots/demo-en-poster.png)

## 它到底解决了什么

一次市场判断的成本，大头从来不在"判断"本身，而在：

- **重新拼装**——价格在一个屏，资金费率在另一个屏，日历在浏览器标签里，流动性在表格里，故事在你脑子里；
- **防守**——有人问这个数字哪来的，你得靠截图把过程重建一遍；
- **后视镜**——你想回看当时那个判断，工具却给出今天修订后的值，悄悄改写了你当时知道的东西。

MacroBay 把这三件事收敛成同一个东西：一个带着证据的结论。

## 行情软件给不了你的

**一、每条判断都带时间边界。**
每份分析都写明观测时间和查询使用的 `asOf` 截止点。后来的修订不会被回填进更早的答案——9 点读一次、
21 点读一次，是两个都站得住的答案，而不是一个被悄悄更新的答案。

**二、事实、假设、条件、缺口是结构上分开的。**
不是写作风格，是输出契约。画面缺一块，分析会指出缺的是哪一块，而不是拿一个中性值顶上。这才让它
能进复盘、进备忘、进仓位讨论。

**三、覆盖缺口是看得见的。**
来源健康本身就是输出的一部分。什么都没发生时，你能分清是"没有消息"还是"没有覆盖"——这是安静的市场
和盲区之间的区别。

**四、一屏，而且已经归一化。**
资金费率与持仓、稳定币供给与 ETF 流向、风险偏好、DXY／黄金／QQQ／美债 10 年期，和 BTC、ETH
放在同一把尺上，外加会给这一切重新定价的宏观数据。

**五、整套东西归你。**
本地优先、MIT、自己的 Key、自己的模型供应商。来源注册表是数据驱动的，缺一路数据是配置问题，
不是 fork 问题。

## 怎么接进你现有的流程

| 你在做什么 | 用它做什么 |
| --- | --- |
| 早盘准备 | 一遍扫完资金费率、流向、情绪和日历，而不是开五个标签页 |
| 写一段判断 | 把结论连同证据引用、成立条件、缺口一起留下来 |
| 复盘会上被质疑 | 点开读数，给出处和观测时间，问题就结束了 |
| 事后归因 | 按当时的 `asOf` 重读答案，而不是今天的修订值 |
| 模型或数据评估 | 换供应商，分析契约不变 |

## 它不做的事

- 不下单、不做仓位管理，也不连券商或交易所账户。
- 不替代机构终端：来源是一批精选的免费和低成本数据，不是完整行情授权。
- 不告诉你买什么。它让你的推理可以被检查。
- 目前是 alpha：接口和 schema 还不承诺稳定，部分来源仍标记为待接入。

## 怎么快速配到能用

1. 添加模型供应商，选一个 Agent 兼容的模型。
2. 启用你已经有权限的数据源，够用就行；没开的会以缺口形式留在画面上。
3. 打开看板，问一个你本来就知道答案的问题，看它有没有引到正确的证据。这是校准信任最快的方式。
