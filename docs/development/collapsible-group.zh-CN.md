# 可折叠分组

需要「头行一行字、点开出现一块内容」的地方，用 `@platform/ui/components/collapsible-group` 的
`CollapsibleGroup`（内部是 antd `Collapse` 的 `ghost` 形态）。**自绘头行与箭头只许出现在这里**：
调用方不许写 `<details>`、不许自己拼「头行 + 展开区」、不许各画一种箭头。

## 壳里固定四件事

- **箭头在最右**，展开时转 180°；
- **展开动画**由 antd `Collapse` 提供，不自己写高度过渡；
- **`aria-expanded` + `aria-controls`**：rc-collapse 只发前者，所以 id 由组件生成、挂到展开区上，
  再把 header 指过来；
- **整行可点**：点标题、计数或箭头都算，不必瞄准 14px 的箭头。

## 三条实现约束

- **多组各自独立**（每组一个 `Collapse`，不做手风琴）；
- **默认收起**，展开态不持久化、不进 URL；
- **展开区自己滚、头行不滚走**（`maxBodyHeight`，默认 320），滚动条只出现在展开区里。

## 内容：`rows` 与 `children`，只能给一种

| 形态 | 用在哪 | 壳提供什么 |
| --- | --- | --- |
| `rows` | 一组行 | 行级语义：`StatusPill` 槽、右对齐时间、带动作时整行是按钮 |
| `children` | 其它内容（表格、表单、说明块） | 只有上面那些行为，**不提供行级语义**；自绘内容里的可访问性由作者负责 |

两者是互斥联合：同时给或都不给，编译不过。

## 收起的内容是「挂载但隐藏」，不是「不存在」

因为 `aria-controls` 必须指向**确实存在**的节点，展开区从首帧就渲染，收起时是 `display: none`。
所以**判据要断「是否可见」，不要断「DOM 里有没有」**——断言「零节点」的用例和这个组件天然打架。
（别处那条「DOM 命中 0」是针对正文文案的，不是针对折叠内容，两件事别混。）

## 用了它之后怎么验

1. 键盘：Tab 到头行、回车/空格展开，展开时头行不动、只有展开区在滚；
2. 同一页两组各自开合，互不影响；
3. 用**真实数据量**的长列表验证（不是两三条夹具）：滚的是展开区，头行不离开面板。
