# 悬停提示

挂在触发器上的简短解释一律渲染 `@platform/ui/components/tooltip` 的 `Tooltip`。不要用原生 `title`：
它只跟着鼠标走、也进不了可访问描述，键盘用户永远看不到。

**气泡挂在 `document.body` 下。** 触发器常住在会裁切（`overflow: hidden`）、会变换、或首帧还没参与布局的壳里；挂在这种触发器旁边的弹层会被裁掉，或者被量成 `(0, 0)` 落到窗口角落。容器由组件写死，不由调用点传。

## 组件

| 导出 | 用途 |
| --- | --- |
| `Tooltip` | 一条提示，挂在一个可聚焦触发器上。 |
| `TooltipProps` | props 类型。 |

文案上限——**20 个汉字 / 44 个英文字符**（12px 字号、250px 气泡下还能保持一行的极限）——是文档与
验收口径，不是代码常量：一条只断言「常量等于 20」的用例永远通过，它不守护任何真实行为。

```tsx
import { Tooltip } from '@platform/ui/components/tooltip'
```

**基础：antd `Tooltip`。** 定位、翻转、窗口内夹取都由库负责；本组件补的是「可聚焦触发器」和文案规则。

### props

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `labelKey` | `K extends string` | 二选一 | 提示文案，**收键**。`K` 由 `resolveText` 反推：解析器的参数是键联合时，允许的键就被锁在联合里。 |
| `dataText` | `string` | 二选一 | 提示**本身就是运行时数据**（新闻标题、品种名）。只准来自变量，不许放字面句子。 |
| `labelParams` | `Readonly<Record<string, string>>` | 否 | 填进模板 `{name}` 的值，**只收已经格式化好的字符串**（`Finder`、`289/289`）。 |
| `resolveText` | `(key: K) => string` | 是 | 调用方的解析入口；未知键解析成空串。 |
| `children` | `ReactElement` | 是 | 触发器，必须可聚焦——按钮、链接或带 `tabIndex` 的元素。 |

`labelParams` 与 `IconButton.ariaLabelParams`、`Popover.labelParams` **同形、同一份实现**
（`fillLabelParams`）：值由调用方格式化好传进来，组件内不再格式化；缺参数时占位符原样保留，
不安静地少一个对象名。带对象的提示（「在 Finder 中打开」）**仍然只有一行**——多行解释走
`Popover.lines`，`labelParams` 不是用来拼段落的。

没有 `placement`、没有 `open` / `onOpenChange`、也不放富内容：触发方式和位置是固定行为，不是调用点选项。
气泡在触发器下方，只有空间不足时才向上翻转。

## 组件自己保证的几条

- **聚焦立即显示**，悬停等 300ms。读者已经用 Tab 明确指过来了，让人再等就是本组件要修的那个毛病。
- **句子为空就不渲染提示**，也绝不回退键名：把 `ui.tooltip.refresh` 念出来比不说更糟。
- **不套包裹元素**：触发器原样透传；包一层会改掉父级布局，也是「可聚焦包裹」那种变体的入口。
- **禁用元素不挂提示**：禁用接不到焦点，提示只剩鼠标能看。原因要写成可见说明。这条由调用点扫描
  （`tooltipCallSiteGuard.test.ts`）执行：`<Tooltip>` 的触发器带 `disabled` 即红。

## 调用点的规则

- 只写一行：**最多 20 个汉字 / 44 个英文字符**。更长就改成可见说明或折叠详情——提示不是文档。
- 提示只做解释，不能是某条信息的唯一载体。丢了提示就丢了信息，那它该写在页面里。
- **键集固定时用类型收口**：解析器的参数写成键联合（例如 `(key: AgentTooltipKey) => string`），
  `labelKey` 就变成编译期检查——键放进常量、包一层函数也逃不掉。扫描守卫只看字面量，
  传参这一半只能靠类型。联合从产品文案的子树派生（`platform/i18n` 的 `DotPaths`），
  **不要对整张文案表求联合**，否则改一句文案全量重编。
- **句子由数据拼出来的提示不迁移**：保留 `aria-label`，它本来就是这一行的可访问名，读的是同一件事。
  也不加 `params`——读者得悬停才知道一句话说的是什么，正是本组件要收掉的东西。

## 怎么验用了它的页面

1. **键盘**：Tab 到触发器，提示立即出现；Esc 关闭且焦点停在触发器上。
2. **鼠标**：悬停约 300ms 出现，移开消失。
3. **名字**：提示进的是触发器的可访问描述（`aria-describedby`），不是 `title`。
4. **长度**：提示在规定的字数内保持一行。
