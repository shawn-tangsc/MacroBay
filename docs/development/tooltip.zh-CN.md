# 提示

挂在触发器上的简短解释一律渲染 `@platform/ui/components/tooltip` 的 `Tooltip`。不要用原生 `title`：
它只跟着鼠标走、也进不了可访问描述，键盘用户永远看不到。

## 组件

| 导出 | 用途 |
| --- | --- |
| `Tooltip` | 一条提示，挂在一个可聚焦触发器上。 |
| `TOOLTIP_MAX_CJK` | 28 —— 中文提示的字数上限。 |
| `TOOLTIP_MAX_LATIN` | 60 —— 英文提示的字符上限。 |
| `TooltipProps` | props 类型。 |

```tsx
import { Tooltip } from '@platform/ui/components/tooltip'
```

**基础：antd `Tooltip`。** 定位、翻转、窗口内夹取都由库负责；本组件补的是「可聚焦触发器」和文案规则。

### props

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `labelKey` | `string` | 是 | 提示文案，**收键**。 |
| `resolveText` | `(key: string) => string` | 是 | 调用方的解析入口；未知键解析成空串。 |
| `children` | `ReactElement` | 是 | 触发器，必须可聚焦——按钮、链接或带 `tabIndex` 的元素。 |

没有 `placement`、没有 `open` / `onOpenChange`、也不放富内容：触发方式和位置是固定行为，不是调用点选项。
气泡在触发器下方，只有空间不足时才向上翻转。

## 组件自己保证的几条

- **聚焦立即显示**，悬停等 300ms。读者已经用 Tab 明确指过来了，让人再等就是本组件要修的那个毛病。
- **句子为空就不渲染提示**，也绝不回退键名：把 `ui.tooltip.refresh` 念出来比不说更糟。
- **不套包裹元素**：触发器原样透传；包一层会改掉父级布局，也是「可聚焦包裹」那种变体的入口。
- **禁用元素不挂提示**：禁用接不到焦点，提示只剩鼠标能看。原因要写成可见说明。

## 调用点的规则

- 只写一行：**最多 28 个汉字 / 60 个英文字符**。更长就改成可见说明或折叠详情——提示不是文档。
- 提示只做解释，不能是某条信息的唯一载体。丢了提示就丢了信息，那它该写在页面里。

## 怎么验用了它的页面

1. **键盘**：Tab 到触发器，提示立即出现；Esc 关闭且焦点停在触发器上。
2. **鼠标**：悬停约 300ms 出现，移开消失。
3. **名字**：提示进的是触发器的可访问描述（`aria-describedby`），不是 `title`。
4. **长度**：提示在规定的字数内保持一行。
