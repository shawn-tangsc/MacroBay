# 提示

操作之后的一句话走 `@platform/ui/components/toast` 的 `ToastHost` + `useToast()`；
需要读者做决定的用 `Modal`，不是提示。

宿主**每个渲染根挂一次**（主窗与每个分离窗各一次）；没挂宿主的窗口里，提示弹不出来。
宿主**不收解析器**：`mi.*`、`storage.*` 这些键属于各产品自己的文案表，壳层没有也不该有一张全仓
扁平表。每次调用自带 `resolveText`，句子在**入队时**解析成快照，宿主只渲染快照。

### API

| 导出 | 用途 |
| --- | --- |
| `ToastHost` | 队列与提示区，挂在你的树外面，一次。 |
| `useToast()` | `success` / `info` / `danger`；没挂宿主时抛错。 |
| `TOAST_CLOSE_KEY` | `ui.toast.close`，关闭键的读屏名。 |

| 调用 | 停留 | 说明 |
| --- | --- | --- |
| `toast.success({ titleKey, resolveText, descKey?, action? })` | 3s | |
| `toast.info({ ... })` | 3s | |
| `toast.danger({ titleKey, action })` | 6s | `action` **类型上必填**：读者只能读到一句"失败了"，等于只说了一半。 |

## 组件自己保证的几条

- **最多两条**：第三条挤掉最旧的，不排队；挤掉时**不抢焦点**——读者可能正在弹窗里打字。
- **悬停或聚焦暂停，离开后恢复的是剩余时间**，不是重新计时。重设一个完整时长会让读者白看三秒，测试也看不出来。
- **提示区是穿透的**（`pointer-events: none`），只有单条提示可交互。右下角那块是隐形矩形，设成可交互会罩住页面自己的按钮。
- **层级 1600，压在弹窗之上**（抽屉层是 1500）：读者刚关掉弹窗就出现的提示，不能被弹窗盖住。层级不是 prop。
- **礼貌播报**：`role="status"` + `aria-live="polite"`，不用 `alert`，也不抢焦点。
- **进场只动 opacity 与 4px 位移**，时长走 `--motion-toast-in`。动尺寸或位置会把整页带着抖；
  降级只有一处：`tokens.css` 在 `prefers-reduced-motion` 下把 `--motion-*` 全部归零。
- **关闭键归组件**，名字取自组件自己的文案表——调用方的解析器可能返回空串，空串就是没有名字的按钮。

## 怎么验用了它的页面

1. 触发一条成功提示：右下角出现，约 3 秒后自己走。
2. 在它快消失前把鼠标移上去：不走；移开后按**剩余时间**离开。
3. 连触发三条：只剩两条，最旧的那条消失，焦点始终没被拽走。
