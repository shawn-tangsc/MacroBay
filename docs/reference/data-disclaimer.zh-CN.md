# 数据与第三方服务

MacroBay 是一个桌面客户端。它不运营行情数据服务，不转售数据，也不为第三方内容提供托管代理。

## 许可证覆盖什么

仓库的 MIT 许可证只覆盖源代码。它**不授予**任何行情、新闻、交易所公告、日历条目或其他第三方内容的
使用权。

数据仍然受产生它的服务条款约束。

## 示例数据

示例场景包含从公开来源、以及从你自己配置的授权供应商处观测到的**聚合数值**（例如 ETF 流向与指数点位）。
它随应用分发，目的是让人离线评估产品：它不是数据源、不会更新，也不得转售或替代供应商授权。
参见[示例数据](./status-and-limitations.zh-CN.md#示例数据)。

## 本项目不做什么

- 不内置行情数据、供应商账号或 API Key。
- 不通过 MacroBay 服务器代理请求。
- 不销售、转授权或再分发行情数据。
- 不保证来源可用、准确、完整，或已授权给你使用。

## 你的责任

如果你配置供应商或数据源，你需要自行负责：

- 在需要时申请账号和 API Key；
- 遵守该供应商的条款、限流、署名要求和使用限制；
- 判断你的使用属于个人、内部还是商业用途；
- 存储和备份你获取的数据；
- 在分享截图、日志或导出内容前移除凭据和个人数据。

供应商可以随时变更、限制或撤销访问。

## 公开页面与未文档化接口

部分 adapter 会读取供应商的公开网页或未作为稳定 API 文档化的端点。这类访问可能受供应商条款限制，
也可能无预警失效。它不构成背书、授权或持续可用性保证。

如果供应商要求移除或调整某个集成，请在仓库里开 issue，以便审查该 adapter。

## 测试 fixture

仓库里有少量供 parser/adapter 测试使用的 fixture。它们是测试输入，不是产品数据 feed，不授予任何
数据权利，也不应被当作行情数据复用。

公开版本会尽量把真实抓取样本替换成合成 fixture。如果你认为某个文件包含不应分发的内容，请开 issue，
附上文件路径和请求依据。

## 无担保、不构成建议

软件和获取到的内容按“原样”提供，不附带任何担保。市场情报输出是决策辅助，不构成投资、法律、税务
或会计建议。

本仓库不授予任何再分发第三方内容的权利。

## 报告问题

请在 GitHub 开 issue，说明：

- 涉及的文件或 adapter；
- 供应商和相关条款；
- 问题是关于代码、fixture 还是文档。

本页是项目政策，不构成法律意见。
