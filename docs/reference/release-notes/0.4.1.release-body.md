MacroBay 0.4.1 - phone push works again, the BLS official calendar turned off, and calendar notifications limited to the countries you choose

✨ New

• Calendar countries Which countries the calendar reports is now a setting — the United States only (the default), all countries, or a list of up to eight. Untouched, nothing changes.
• Silence notice A news source with no new item for 24 hours says so; other sources use 12 hours on weekdays and 24 at weekends. These stay in the centre and on the desktop, never on your phone.
• Push threshold Sentiment push strength is yours to set — low, medium, high; the default stays medium.
• Analysis retry When the latest conclusion cannot be read, the card says it is unreadable and offers "try again", which reads again only: no new analysis, no quota spent.

🔧 Fixes

• Push Nothing reached your phone: the delivery path never received the channel to use, so every attempt failed as "no channel" while the channel itself was healthy and the test button on the channel page still worked. Push, redelivery and the three test buttons now share one entry point.
• Push reasons A failed delivery now names which of five causes it was — no channel wired, more than one, a channel type that cannot notify, no credential, not enabled — instead of one sentence for all of them.
• Notifications The centre no longer drops a record after a reload just because it carries the finished sentence and not the old body, and the reason a record was rejected is no longer swallowed before it reaches the log.
• Analysis notice "Analysis recovered from failure" was refused on every submit — its request lacked the list delivery requires — and vanished without a trace; fixed, and the cast that hid the error is gone.
• Runtime The notification runtime could be created before the configuration finished, freezing "no push hook" for the whole process; it is ordered now, with a guard against it happening again.
• Calendar A stopped official feed no longer looks healthy — its refresh is greyed with a reason — and a month that cannot be read says so instead of showing an empty month.
• Interface Explanatory sentences moved out of settings rows into the info popover; failures, conflicts and blocked states stay in the row.
• Validation Sentence patterns over Chinese prose are gone (they missed new wording and rejected legitimate wording); a percentage in the text must now exist in the snapshot it cites.
• Conclusion detail A detail carrying one key this reader did not know was judged unusable as a whole; fixed.

⚠️ Before upgrading

• Not signed, not notarised: on macOS right-click → Open on the first launch; on Windows choose More info → Run anyway in SmartScreen. Both repeat with every update.
• The BLS official calendar is unreachable — the source returns 403 — so its automatic sync is off; the events already stored are from 22 October and carry no release time.
• Calendar notifications still report the United States only unless you change the new setting.
