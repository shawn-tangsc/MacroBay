# MacroBay 0.4.1

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，然后
   **右键（或 Control）点击 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；Windows 上运行
   安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
2. **美国劳工统计局的官方日历目前取不到（对方返回 403），自动同步已停用。** 日历里现有的这批数据
   停在上一次成功同步（10 月 22 日），这些事件**没有发布时间**——不再显示一个编出来的时刻。你的数据
   不会被删除；等对方能取到时，同步可以再接回来。

## 你会看到的变化

### 手机推送修好了；推不出去时，它会说是哪一种原因

- 有一段时间几乎什么都到不了手机：投递那条路从来没有拿到「该用哪个通道」，于是每次尝试都以
  「没有通道」失败——而通道本身是好的，通道页的「发送测试消息」照样能发，所以看起来像通道坏了，
  实际是推送这条线整程失效。现在推送、重投、测试按钮共用同一个取用通道的入口，三条路一起恢复。
- **产品自己的通知设置里那三枚测试按钮，现在真的能发出去。** 之前它们拼出来的请求少了一样投递前必读
  的东西，还没出门就被拒了。
- **推不出去时，记录里会写清是哪一种**：没有接入通道、接了不止一个、这个通道的类型不能发通知、
  凭据还没填、或者没有启用。五种原因以前共用一句「没有可用通道」，等于什么都没说。

### 通知中心不再丢记录，也不再吞掉原因

- **重开应用后记录不会再消失。** 只带成品句、没有旧格式那份文案的记录，加载时会被判成「没有正文」
  丢掉，而丢掉这件事又被写回文件，于是一去不返。现在两种正文来源认一种就留。
- **一条通知为什么被拦下，现在会写进日志。** 这个原因以前是生成了又在写日志前被吞掉的，所以「今天几乎
  没推送」查不动；现在日志带上原因、事件与来源，且只带这几类字段。

### 「分析已从失败恢复」不会再静默消失

这条通知**每次提交都会被拒**，因为请求里少了一份投递前必经的清单；它哪儿都没出现，也没有任何提示。
现在每一种分析通知都带全了，那个把错误藏到编译期的写法也删掉了。

### 日历：停掉的源看起来就是停掉的，读不到的月份就说读不到，国家由你选

- **停掉的官方日历不再装成健康。** 它的刷新按钮变灰并说明原因，而不是把一份永远不会更新的数据画成正常。
- **读不到的月份说「读不到」，不写「这里没有事件」。** 以前这两种长得一样，于是一次网络故障会被读成
  一个空的月份——现在它们用两句话、两种状态，并且都告诉你下一步能做什么。
- **不可用的源不再显示成健康**，在它出现的每一处列表里都是这样。
- **日历报哪些国家，由你选。** 这是情报通知设置里的一行；默认仍然只报美国，你不动它就完全不改变行为。

### 主页：最新一条 AI 结论读不到时，有出口

- 读不出来时，卡片会说清是读不到，并给一个**「再试一次」**；不再是整块「不可用」、点了也没反应。
- **重试只重新读取**：不会重新跑分析，也不花额度。

### 还有一些看得见的小改动

- **舆情推送的强度门槛可以自己设**：弱 / 中 / 强，默认仍是中——不改就还是原来的行为。
- **新闻源安静下来时，按工作日 12 小时、周末 24 小时判**，而且只说「这个窗口里没有新内容」，
  不再猜它停更了。
- **日历预期值缺失有三种回答**——没有公布、还没有值、读不到——不再把其中两种合成一句。
- **日报失败的句子不再说它不可能知道的时长**；一次停住的回合会说清是三种里的哪一种，不再一个词包打天下。

## 已知限制

- **Windows 安装后的运行态仍未在真机上验收**：安装引导页、快捷方式、通知与任务栏分组都还没验过。
- **企业微信通道只是占位**，运行时一定失败；另外五家（Telegram、Slack、飞书、Discord、QQ）是真实实现。
- **判断对错暂时没有结论**：要判一条判断是对是错，需要判分能力，这一版还没有——所以现在不公布任何
  准确率，一条都还没判。
- **劳工统计局日历里的这批事件没有发布时间**，直到官方来源能取到为止。
- **没有自动更新通道**，Linux 未打包。版本提示只告诉你「有新版本」，下载和安装仍然要你自己来。
- Windows 上托盘图标由空图创建，实际不可见；「用其他应用打开」目前只支持 macOS。
