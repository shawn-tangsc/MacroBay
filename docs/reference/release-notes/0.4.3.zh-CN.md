# MacroBay 0.4.3

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 下载

- macOS · Apple 芯片：`MacroBay-arm64.dmg`
- macOS · Intel：`MacroBay-x64.dmg`

**Intel 版状态。** Intel 版是 `MacroBay-x64.dmg`：**它由发布 workflow 构建，但尚未在 Intel 真机上验收。**
Apple 芯片的下载链接不变，`latest-mac.yml` 仍只由 arm64 job 产出。

产物未签名、未公证，首次启动仍需按下面「升级前请先看」的两步放行。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，然后
   **右键（或 Control）点击 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；Windows 上运行
   安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
2. **美国劳工统计局的官方日历仍然取不到（对方返回 403），自动同步保持停用。** 日历里已有的那批数据
   停在上一次成功同步，这些事件**没有发布时间**——不显示一个编出来的时刻。你的数据不会被删除。
3. **旧的日报生成计划会被补齐，不会被清空。** 升级只搬数据：旧文件只读、不删也不改，写新数据失败就整体
   放弃、下次重试。以前读出来缺语言的期会被补上语言，而不是看起来像计划丢了。
4. **改一期不再牵连其他期。** 新增、编辑或删除某一期只写那一条；眼下读不出来的那一行也留在文件里。

## 你会看到的变化

### 情报源：一行回答四个问题

- **每个来源的详情多一块健康四格**：今天有没有读数、上次成功是什么时候、为什么没在采、能不能立刻采。
  这四格的判断都来自同一次读取，页面自己不另算一遍——所以左栏的点和这里的药丸不会互相矛盾。
- **第四格答「可以」时，那里多一颗「立即运行」**：跑的时候按钮不可点，同一行只有状态词「正在运行」
  （读屏也听得到）；「跑完会自动恢复」那句解释搬进了按钮旁的问号里。跑完结果留在那一行——成功带服务端
  摘要，没成带原因，不是弹一下就没了。
- **读不到就是读不到，不再画成「没有数据」**：读失败显示错误态并可重试，重试只重读这一个源。日历那类
  来源只按提供方汇总运行、没有逐次记录，两格写「未知」并说明原因。
- **来源健康从「只会亮、不会变色」变成五档**：正常、连续失败、数据过期、失败、未启用分别可辨；左栏目录点
  与详情药丸读的是同一个判断。颜色不单独承载信息——环形与实心是形状的差别。
- **不可用的来源，收起时头行挂一枚「暂不可改」**：整句原因仍住在展开区的第一行，收起态不再冒充可用。
- **顶部横幅只说一件事**：「已经配了但没通」。还没配这件事改用药丸表示，两种状态不再长得一样。
- **灰掉的原因码搬进问号里**：正文只说人话（比如官方日历为什么取不到），技术原因收进紧挨着的 ⓘ。

- **两处改同一份设置，不会互相冲掉**：在另一处保存后这一处会自己重读；你正在填、有改动时不会被覆盖，页面
  顶部出现一句「另一处已修改了这里的设置，你正在填的内容没有动」，你可以「重新载入」或「继续编辑」。

### 日报：混进另一种语言就整期不发

- **同一期里混进另一种语言时，现在只重写一次**（以前会把三次重写预算全花在同一段外语上）；仍然混，
  **整期不发**，你看到失败行与原因、可以重试。不删段、不自动翻译。判定看的是书写系统（英文期里有
  中日韩文字、中文期里有整段英文），不是靠句式或词表猜。
- **每一期的语言行行尾多了一个「打开会话」**：只在该期该语言最近一次生成所用的会话存在时出现；点开就落到
  那条会话，会话已经不在了就地写一句「这条会话已经不在了」，不跳转。删除仍在右键菜单里。
- **旧期没有可打开的会话就不显示这个动作**——这是有意为之，不是漏了：那期本来就没有会话可以打开。

### 通知与频道：测试按钮与运行记录

- **舆情提醒、日历·开始前、日历·发生后这三处配置下方多了「测试」按钮**：它真的提交、真的走手机通道、真的
  留一条回执，成功句是「已发到 {通道名}（测试）」——没真发出去就不会这么写。此刻没有恰好一条可用通道时
  按钮不出现（不是变灰）；点的时候有多条会拒绝并说明当时有几条。
- **另外两处（模块信号触发、日报已完成）没有测试按钮**：给它们做测试只能拿一件真实的业务事件当载体，那条
  假事件会以那件事的名字出现在通知中心里——宁可没有，也不造一条假事。
- **频道运行记录按频道查，保留条数有上限**：失败类保留最近 **500** 条、起停类保留 **100** 条，**每天清理
  一次**（读者本地时区 03:04）。更早的会被删掉。

### 三处「能改、其实没用」的设置撤掉了

这几处都有一个共同点：**控件在、能保存，但没有任何东西读它**——或者反过来，画了一个改不动的项。留着只会
让你以为设置起了作用。

- **「触达面」那一行不再列「通知中心」**：它从来不是可选项，通知中心一直都会记录；这句话现在写在那一行的
  问号里，不再在控件里造一个勾着又取消不了的项。
- **频道的新建/编辑弹层不再有「权限模式」和「工作目录」两栏**：那个频道的会话权限取自它绑定的智能体配置，
  工作目录用的是智能体工作区——这两栏存下来没有任何东西读。**已设过的不受影响**：存储列还在、值原样保留，
  只是不再从界面上写入。
- **模型服务页撤掉了「更多默认模型设置」按钮和它下面的「绘画模型」**：绘画生成路径从来没读过这个默认值，
  选了等于没选。已设的值保留、不迁移，也不因为撤了控件就被清掉。

### 会话：自动会话不再把你的会话挤下去

- **日报的编辑会话不再算进你的会话列表**：以前每生成一次就多一条，列表很快被它淹掉、你想找的会话要往下翻。
  现在按身份区分（期 × 语言），历史副本也按字段判断、不靠名字猜。
- **市场解读的弹窗不再空白**：以前库里有会话、打开却是空的（只有一条系统消息），现在会话能正常落消息；
  写入失败会留下痕迹，不再静默变成空白。

### 看板右栏：三种状态各说各的

右栏那三行说的是「这一格现在读出来没有」，不是「这个来源好不好」——所以状态词从「可用／不可用」改成
「**读到／读不到**」。

- **日历行分三档**：日程读到 / 本月无日程 / 日程读不到。「这个月本来就没有安排」不再和「日程读不到」
  共用一句话——前者不是故障，后者是错误态、可以重试。
- **指数与持仓多一档「偏旧」**：指数偏旧 · 截至 {时刻}、持仓偏旧 · 截至 {时刻}。值可能仍然对，但你能看见
  它旧到什么时刻；这个判断与卡片里那张图用的是同一份读数、同一个阈值，行上不自己判、也不印阈值数字。
- **只有一条腿时整格不翻红**：持仓行会写成「持仓读到，费率历史只有一支」，说清少的是哪一条、为什么。
- **读不到不再画成「没有」**：读失败是错误态并给重试；确实为空才是空态。

### 出问题时不再整窗白屏

- **一块面板里出错，错误关在那一块里**，其余部分照常可用；错误态用统一的状态面，不再整窗白掉。
- **持仓那张卡不再把「数据滞后」说反**：判定改用折叠前的最新读数；观测时间与最新读数不同时，会写成
  「01:00 · 最新读数 01:45」两个数并列，相同时只出现一个。

## 已知限制

- **判断对错仍然没有结论**：要判一条判断是对是错，需要判分能力，这一版还没有。
- **美国劳工统计局的官方日历取不到**（对方 403），详见[状态与限制](../status-and-limitations.zh-CN.md)。
- **通道列表只列出已经能用的**：不能真正收发、或者拿不到凭据的，不放进列表占位。
- **Linux 未打包**；**Intel 版未在 Intel 真机上验收**。
- **手机发回来的消息看不到**：这一版只能确认「发得出去」，看不到手机回过来的内容；要看得先补一个最小的
  入站可见面，本版不做。
- **日报的宏观栏在确实没有高影响事件时，正文一个字都不印**：这是有意的，避免让整份日报读起来像漏了什么。
  这一期确实为空这件事会记在右列的「数据缺口与限制」里，标成「无需处理」。
- **同一件事只提醒一次，升档不再补推**：一条新闻已经按「中」推到手机，后来的报道把它升到「高」，不会再发
  第二条。你可能错过的是「它变严重了」这一声提醒；这条新闻本身还在应用里，最新那条报道的强度照常显示。
- **没有自动更新通道**：版本提示只告诉你「有新版本」，下载和安装仍要你自己来。
