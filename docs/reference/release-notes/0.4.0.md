# MacroBay 0.4.0

What changed for the people using the app, and what to look at before you upgrade a copy you already
run. For what the app can and cannot do at all, see [Status and limitations](../status-and-limitations.md).

## Before you upgrade

1. **This version is not code-signed and not notarised.** First launch takes two steps. On macOS,
   drag the app into Applications, then **right-click (or Control-click) → Open** and confirm
   **Open** — double-clicking is blocked by Gatekeeper. On Windows, run the installer and choose
   **More info → Run anyway** in the SmartScreen dialog. **Both steps repeat with every downloaded
   update.**
2. **The generation time can now be any half hour of the day.** A value you saved earlier is kept.
3. **Briefing history groups by issue instead of by day.** With one issue a day it looks the same;
   with more than one you will see more rows, and the row switches language in place.
4. **A finished brief raises a desktop notification**, which 0.3.x did not. If you would rather not
   be woken, turn the desktop reminder switch off; the record in the centre is still written.
5. **Notifications are no longer ticked one by one**: in-app toasts and desktop reminders have one
   switch each, and the intelligence page chooses which few reach your phone. Existing records in
   the centre are kept.
6. **Analysis quotas are still split by line.** No number changed in this version.

## What's new

### The daily brief: any time of day, and two languages in one issue

- **The generation time is no longer morning-only.** It used to allow a handful of slots that
  amounted to "the morning issue"; now every half hour from `00:00` to `23:30` is available, so an
  evening issue fits. The default stays `07:00`.
- **One issue reads the data once and writes each language from it.** Both language editions cover
  the same numbers with the same cutoff — never one at nine and the other at ten. If a language did
  not come out, that issue is marked incomplete and says which edition is missing, **instead of
  quietly showing one fewer document**.
- **History groups by issue.** It used to group by day, which hid which run a document came from on
  a day with more than one issue. Each issue is now one row, the row switches language in place, and
  every attempt is listed — including the one that failed.
- **Manual generation is limited to the last three days.** Rerunning anything older is refused:
  every run is a model call, and a UI cannot be the only thing stopping a bug.

### Notifications: they will wake you, but a quiet day is still zero items

- 13 platform events and 8 intelligence events, **21 in all**. Which tier each event may reach
  (centre, toast, desktop, channel) is fixed — **there is no per-event subscription**. In-app
  toasts and desktop reminders each have one switch; the record in the centre is written either way.
- **Only four can reach your phone**: a finished brief, a module signal, a macro event, and a
  strong-sentiment alert — and only once you tick them on the intelligence page. Nothing else
  leaves the machine; failures stop at the centre and the desktop.
- **A finished brief now raises a desktop notification.** The in-app toast does not carry this one;
  the reminder goes to the desktop.
- Sentiment alerts to your phone are capped at **five a day**; the rest go to the centre only, and
  the list says how many were held back.
- **Channel delivery**: notifications go out over a channel you have connected — Telegram, Slack,
  Lark, Discord and QQ. Enterprise WeChat is a placeholder and always fails at runtime. Repeated
  failures suspend pushing and leave a record you can read; a recovery leaves another one.

### When a panel rule has something to say, the analysis runs again

- Before, only macro events could trigger a new analysis. Two module rules can now: **an abnormal
  open-interest move (suspected liquidation)** and **an ETF three-day net outflow over the line**.
- The analysis states which rule fired, the reading it used, the threshold it crossed and the tier
  it landed in.
- **The first two weeks only record, and never downgrade automatically.** A rule that fires too
  often will not quietly have its threshold raised; the product decides after two weeks of real
  frequency.
- Interest-rate path, cross-asset and sentiment alerts **are not wired this version**: the first two
  are not worth a paid rule for a crypto-first reader, and the third already speaks elsewhere.

### The sidebar tells you there is a newer version; the About page says what changed

- A dot on the sidebar's Settings entry, **lit only when a newer version is actually known**,
  cleared by opening About, and shown once per version.
- The About page carries the current version, the latest version, a "check for updates" button, and
  **this version's release notes**: read as Markdown, with headings, lists, fenced code and inline
  code rendered as they are; anything unrecognised stays plain text — ugly beats missing a word.
- The download action opens the project's Releases page in your browser. The app **does not**
  download in the background and **does not** install anything.
- A build started from source **never checks for updates and makes no request at all**; only an
  installed build does.

### Capital flow card: three labels on the bars, numbers that agree

- Only three labels on the bars: **largest inflow, largest outflow, last day**. A day that is two of
  those at once is labelled once.
- "Show daily numbers" under the chart lists every day, each cell carrying its unit.
- One unit and one basis, each stated in one place: the chart header gives the unit, the bar labels
  and the table use the same string, both column and row names carry their scope, two sentences say
  the two figures cannot be reconciled, and the date column says "UTC day".

### Three classes of failure fixed: the app not starting, gates misfiring, files left unreadable

- **A Windows launch crash.** The system temp directory can point somewhere the process cannot
  create files; SQLite then fails to open and the app dies before any window appears. Startup now
  probes for writability first, falls back to its own directory, and does that **before any database
  is opened** — any call site that skips it fails at the source instead of on a user's machine.
- **Gates misfiring on Windows.** All three baseline gates whose keys are paths now normalise the
  separator, so they stop treating every file as a new oversized one.
- **A config file torn by a crash used to be permanently unreadable.** Writes go to a temporary file
  and are renamed into place; a torn file is recovered from the backup and the raw bytes are kept.
- **CI has a Windows job for the first time**: typecheck, the three platform-sensitive suites and
  the three path-key gates.

## Known limitations

- **The installed Windows build still has not been checked on real hardware**: the installer
  walkthrough, shortcuts, notifications and taskbar grouping are all unverified. The Windows CI job
  added in this version has not completed a run yet, so treat "it installs on Windows" as unproven
  until it does.
- **The enterprise WeChat channel is a placeholder** and always fails at runtime. The other five
  (Telegram, Slack, Lark, Discord, QQ) are real implementations.
- **The in-product configuration drawer for notifications is not in this version.** The
  notification settings live in settings; opening that configuration from a product page is part of a
  planned settings overhaul.
- **A signal that was squeezed out has nowhere to be seen.** When a run's quota is taken by more
  important signals, the one that lost its slot cannot currently be looked up anywhere.
- **Two acceptance items for the rule chain still need their conditions**: "the conclusion must name
  the module" needs one real analysis run to check, and "record only for two weeks" needs two weeks.
- **There is no automatic update channel**, and Linux is not packaged. The update notice only tells
  you a newer version exists; downloading and installing stay yours to do.
- On Windows the tray icon is created from an empty image and is invisible; "open with another app"
  is macOS-only.
