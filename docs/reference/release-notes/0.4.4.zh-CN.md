# MacroBay 0.4.4

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 下载

- macOS · Apple 芯片：`MacroBay-arm64.dmg`
- macOS · Intel：`MacroBay-x64.dmg`

**Intel 版状态。** Intel 版是 `MacroBay-x64.dmg`：它由发布流程构建并随版本发布，但**还没有在 Intel
真机上跑通首次安装**。Apple 芯片的下载链接不变，`latest-mac.yml` 仍只由 arm64 那条产出。

产物未签名、未公证，首次启动仍需按下面「升级前请先看」第 1 条放行；拖动、右键打开、以及右键菜单
里没有「打开」时的替代路径，都写在仓库文档的「下载与安装」一页。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，然后
   **右键（或 Control）点击 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；右键菜单里没有
   「打开」时（较新的 macOS 版本移除了它），去**系统设置 → 隐私与安全性**点「仍要打开」。Windows 上
   运行安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
2. **一条消息现在可以同时发到多条通道。** 上一版同一时刻只能启用一条通道；这一版可以同时启用多条，
   每条通道各收一份、各自给结果，一条失败不影响其他几条。
3. **美国劳工统计局的官方日历仍然取不到（对方返回 403）**，自动同步保持停用；日历里已有的那批数据
   停在上一次成功同步，这些事件没有发布时间。
4. **两项平台侧开关是前提（同上一版）。** Discord 要先在开发者后台为这个 bot 打开 **Message
   Content**，否则网关会拒绝连接；Slack 要在 App 侧开启 **Socket Mode**。这两项都在平台后台，不在应用里。

## 你会看到的变化

### 舆情：每条新闻可以单独要一次解读

- **舆情列表每一条的右键菜单多了「AI 解读」**：手动要一次对这一条新闻的解读，不用等它被自动选中。
- **结果只落在右侧详情栏的一节里**：标题是「这条新闻对市场的影响」，下面写清这次解读的依据——哪一条
  新闻、解读时用到多少条证据，以及生成时间。
- **同一个位置管三种情况**：没解读过是「AI 解读」，解读过是「查看 AI 解读」，依据变了可以「再次解读」；
  不能点的两档会把原因写在菜单里，不给你一颗按了没反应的按钮。
- **一条中性、没有标的、也没有直接影响的新闻，不再被当成高重要性事件去分析。** 这类新闻只在看板上标注。
- **解读不会永远停在「正在解读」。** 长时间没有结果会落成失败并给「再试一次」；应用关掉再打开，之前
  卡住的那条也会落到失败态，不会一直转。

### 通道：一条消息发给所有已启用的通道

- **同时启用多条通道时，一条消息各发一份**，每条通道有自己的结果与失败原因；其中一条断了，其余照发。
- **回执按这一次发送逐条读出来**：以前手动发送后常看到「只留在应用内，没到手机」，其实是回执没被带
  出来；现在会写明哪条到了、哪条因为什么没到。
- **Telegram、Slack、Discord 现在能收图**：日报的「发布频道」会发出海报图加一段导读；只收文字的通道
  收导读文字，不会装作能收图。
- **通道都没就绪时，设置页不再劝你「停用到只剩一条」**：没启用、和启用了但没连上，是两种处境，分开说。

### 日报与分析：每个数字都要有出处

- **数字出处校验从结论扩到所有会印数字的段落**：情景、传导、催化剂、方向理由里出现快照里没有的数，
  这次分析直接拒收，不会给你一段看起来很顺但数字对不上的分析。
- **「失效条件」不再是一句自由发挥的话**：它改成引用快照里的一条事实或者一个时刻，校验只比数据、不读
  句子；旧记录照旧显示。
- **日报每篇只有一个时点**：以前同一篇里会并排出现两个时刻的数（一个来自上一份分析、一个来自当天窗口），
  现在正文只保留当天这一套。
- **日报多一行「什么会推翻这条判断」**：以前这行恒为空，现在会写出来，页面和导出的文字里都有。
- **分析时间轴分成「成功」和「失败」两个页签**：失败的运行不再混在成功记录里，找一次出错都落空的原因
  时不用往下翻。
- **一次分析的配额按「一次运行」记，失败也计一次**：最坏情况的调用次数写进配额用尽的那句话里，另外能
  看到今天实际调用了多少次。

### 行情与资金面

- **行情卡多了窗口振幅**：窗口内的最高与最低直接标在卡上，不用自己去翻这一段的高低。
- **资金面的净流入柱状图窗口固定**：今天还没有读数时今天不画、窗口往前退一天，仍是同样天数；过去某天
  缺数就留一个空位，不补 0（0 是真实读数），也不删掉那一天。
- **ETF 净流入换了一个更稳的来源**：原来那一路直连经常被挡，随时可能断源；现在采集、看板和日报都按
  新来源解析。

### 日历

- **日历从一整页变成一个抽屉**：点页面里的日历图标，浮层开在当前页上，不再整页跳走；关掉它回到刚才
  那一页。
- **日历通知可以按国家发**：三个选项——只发美国、发全部、或者自己选国家。

### 情报源与设置

- **采集频率的两档真的生效了**：「均衡」和「频繁」以前改完节奏一样，现在按档位取数，实际间隔写在频率
  那行的问号里。
- **频率那一行不再被省略号切断**：具体间隔和下一次读数收进旁边的问号，正文只留「频率 ⓘ + 下拉」；
  改档以后里面的数字会跟着变。
- **核心指标多了取值源**：四个核心指标各自列出由哪个来源供数，每一条腿可以单独关。
- **来源详情里的「官网」按钮按数据画**：只在来源真有官网时出现；和注册地址相同就去重，只留「注册 /
  获取 Key」。
- **「VPN」标签按实测标**：实测不需要代理的来源不再带这个标签。
- **存储页能列出被隔离的损坏副本**：磁盘上被隔离的文件以前看不见，现在会列出来，并说明它是什么、
  能不能删、删了会怎样。

### 出问题时

- **读口挂住不再永远转圈**：读取超过时限会落成失败态并给重试，不再让你分不清「再等等」和「已经坏了」。
- **打开应用时更早看到界面**：启动那段白屏缩短，先出静态框架，再填内容。

## 已知限制

- **arm64 与 Windows 安装包都没有在真机上完成安装验收。** 0.4.0 期间有人在 Apple 芯片机器上实际安装
  使用过，之后没有再做过真机安装验收；Windows 安装器构建通过，安装后的运行态没有验收记录。
- **美元指数可能整段没有数据，这是套餐限制，不是坏了。** 供应商按你现有套餐不提供这一路，那条线会长期
  留一个缺口。续上提供这一路的套餐后，「最近 24 小时」那个窗口大约要一天才画满，缺口那段不会自动补回来。
- **「本段无数据」现在分得清两种原因**：一种是这段时间确实休市，另一种是供应商的套餐不提供这一路——
  后者在图例上直接写「本段无数据 · 套餐不提供」。
- **美国劳工统计局的官方日历取不到**（对方 403），详见[状态与限制](../status-and-limitations.zh-CN.md)。
- **飞书与 QQ 这一版只发文字**：图片出站目前只在 Telegram、Slack、Discord 上开。
- **分析时间轴只列已出结果和已失败的运行**：正在跑的那一刻时间轴里还没有它，结果出来才出现。
- **日报的宏观栏在确实没有高影响事件时，正文一个字都不印**：这是有意的，这一期为空会记在右列的
  「数据缺口与限制」里，标成「无需处理」。
- **同一件事只提醒一次，升档不再补推**：一条新闻已经按「中」推到手机，后来的报道把它升到「高」，不会
  再发第二条。
- **没有自动更新通道**：版本提示只告诉你「有新版本」，下载和安装仍要你自己来。
- **手机上发进来的消息会落成一条普通会话**：名字是渠道名加「对话」——「飞书 对话」「QQ 对话」——在会话
  列表里点开它，就能看到你在手机上发的那句和机器人的回答。
