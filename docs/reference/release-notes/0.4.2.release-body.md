MacroBay 0.4.2 — a more reliable briefing, settings that are no longer lost, and less talk in the interface

✨ New

• Collection policy Each market-intelligence source now has its own collection preset (manual / balanced / high) and its own "include in sentiment analysis" switch. Changes save immediately; a failed save keeps the value you picked and offers a retry.
• Explanatory prose The body keeps only field names, current values and controls; explanations and ranges live in the question mark next to them, opened by hover or keyboard focus. An explanation that earns nothing is deleted.

🔧 Fixes

• Black screen Generating a briefing blanked the whole window: the agent's task panel changed its hook order when it went from hidden to visible, so React unmounted the tree. Generating a briefing is an agent task, so one click crashed it. Fixed.
• Briefing When the model is unavailable, rate-limited or has no key, the issue still publishes its facts and says why; text in another language is rewritten once and, if it still mixes, the issue is not published; a macro column that cannot read the calendar says "unavailable for now" instead of "nothing happened"; a stale row says which day's data it uses; a headline in a different language from the body is marked "original"; copied text matches the body; the issue you are reading is no longer replaced when another run finishes.
• Calendar Standing explanations moved into question marks; event details float above the calendar without squeezing the month column; details gained two timestamps (first stored, first observed release value); an empty page separates "no source enabled" from "no events"; a source with no English items says so.
• Settings When the settings file cannot be read the app starts with defaults and shows the path of the kept copy plus "try reading it again"; "reset settings" sits separately in the danger zone. An unreadable file is no longer treated as empty and overwritten.
• Sidebar The session list has a single scrollbar again, and session names no longer show internal identifiers.
• Data An unreadable record keeps its original file and a copy — briefing history, past judgements, settings, briefing AI settings, the push threshold, calendar reminders; briefing history hidden by an earlier upgrade comes back; a broken sentiment store is no longer rebuilt from scratch on its own.
• Push Telegram reconnects by itself and says "retrying", "recovered" or "stopped"; the test-notification button no longer fires repeatedly on double clicks.
• Time and state A clock with a time zone no longer prints its offset twice; one missing series no longer hides a whole block — the other is marked "unknown" with a reason; an incompatible data format says "quit the app completely and reopen" instead of offering a retry that does nothing.

⚠️ Before upgrading

• Not signed, not notarised: on macOS right-click → Open on the first launch; on Windows choose More info → Run anyway in SmartScreen. Both repeat with every update.
• "Collection policy" no longer carries an "enabled" switch: enabling is that source row's switch only — two switches for one fact undid each other.
• The collapsed "automatic sessions" summary no longer stays pinned to the bottom of the panel; scroll to the end of the list to see it.
• The BLS official calendar is still unreachable (the source returns 403), so its automatic sync is off; stored events stop at 22 October.
