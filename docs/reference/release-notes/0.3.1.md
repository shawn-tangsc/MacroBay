# MacroBay 0.3.1

What changed for the people using the app, and what to look at before you upgrade a copy you already
run. For what the app can and cannot do at all, see [Status and limitations](../status-and-limitations.md).

## What's new

### Notification centre

A bell in the top bar carries an unread count and opens a drawer on the right, so checking what
happened does not take you off the page you were on.

- Unread items come first, newest first, and unread is marked with the accent colour — not red.
  Red means a failure in this app; an unread briefing is not a failure.
- Every notification carries the action it is about: open the task, open the briefing, check the
  source. A notification that cannot lead anywhere is an alert you cannot act on.
- "Clear" marks everything read. It does not delete anything.
- The first real source is a task that fails: one notification per task per day, with the failure
  reason when the task recorded one, and a way back to that task.
- Notification settings gained a "send a test notification" control, which proves the path end to
  end and describes no real event.

### One boundary for "a day"

The briefing generation time, task schedules, quiet hours and the analysis day now all follow the
time zone you set in settings, resolved in one place rather than several. Times shown in the
interface carry a `GMT±n` suffix, so a time is never displayed in local time while labelled UTC.

### Proxy

- A malformed proxy address is refused when you save it, and says why, instead of silently becoming
  a direct connection.
- The self-check reports the path that was actually resolved, not the string you typed, and does not
  report success when the result is a direct connection.
- A 401, 403 or 404 from the target says the target refused the request; it no longer blames the
  proxy for it.
- Bypass rules have one implementation, so Chromium traffic and WebSocket traffic follow the same
  rules.

### Cache maintenance

Refresh re-inspects every cache instead of reading a stale in-memory value, and two refreshes
started at the same time share one inspection and then re-read. A failed inspection is reported as
failed rather than replaced by the previous value. The compaction figure is the difference in record
size before and after, not the size of the whole record.

### Interface

Empty, error and disabled states, icon-only buttons, status words and context menus each have a
single implementation, and the tooltip is reachable from the keyboard and stays below the thing that
opened it. Status wording now separates "never ran", "not yet", "running", "failed" and
"unavailable" instead of using one word for two situations.

### Defaults

Two first-run defaults changed, so a new install opens differently:

- The display style defaults to **dark** rather than following the system.
- Proxy mode defaults to **follow the system proxy** rather than a direct connection, so outbound
  requests consult the system proxy settings first.

### Channels

Channel maintenance runs as platform jobs, so entries such as "audit cleanup" and "delivery retry"
no longer appear in the settings task list. Their runs are still visible in the task run history.

## Before you upgrade

1. **This build is not code-signed and not notarized.** The first launch takes two steps. On macOS,
   drag the app into Applications, then right-click (or Control-click) it and choose **Open**, then
   confirm **Open** — double-clicking is blocked by Gatekeeper. On Windows, run the installer, then
   in the SmartScreen dialog choose **More info → Run anyway**. Both steps repeat with every
   downloaded update. If macOS still refuses, run
   `xattr -dr com.apple.quarantine /Applications/MacroBay.app` and open it again.
2. **Switching time zone can move today's briefing edition.** The edition already generated for
   today stays as it is; a new one may be placed under the new zone.
3. **Market-open de-duplication records are laid down again in UTC once**, with at most one extra
   analysis per slot.
4. **Old semicolon-separated proxy bypass rules are normalised to the comma form.** Fragments
   without a host name (for example `:1`) are dropped; forms that are not supported (for example
   `10.0.0.0/8`) are kept exactly as written and are only refused when you edit network settings,
   with the offending entries named.
5. **The analysis quota is now split, and the total is larger**: data 60 per day and 15 per hour,
   calendar 9 per day and 3 per hour, quotes 3 separately. This loosens the earlier 12 per day; it
   does not tighten it.
6. **Channel maintenance tasks no longer appear in the settings task list.** That is deliberate,
   not a lost task.
7. **The new defaults apply to a fresh install only.** A machine that had saved any settings before
   the upgrade keeps its existing display style and proxy mode; to switch to dark or to follow the
   system proxy, change them in settings.

## Known limitations

- The Windows installer is built and its contents are checked, but the installed app has not been
  verified on Windows hardware yet: installer pages, shortcuts, notifications and taskbar grouping
  are unverified.
- There is no auto-update channel, and Linux is not packaged.
- The installer brand images are produced by a local script that is not in the repository, so they
  cannot be rebuilt from the repository alone.
- On Windows the tray icon is created from an empty image and is therefore not visible, and "open
  with another app" is macOS-only.
