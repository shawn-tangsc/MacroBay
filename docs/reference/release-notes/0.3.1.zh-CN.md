# MacroBay 0.3.1

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 你会看到的变化

### 通知中心

顶部功能区多了一个铃铛，带未读角标；点开是右侧抽屉，查完就回去干活，不用离开当前页面。

- 未读排在前面、组内按时间倒序；未读用强调色圆点，**不用红色**——红色在本应用里表示出错，
  一条未读的日报不是出错。
- 每条通知都带着它指向的那件事：打开任务、打开日报、检查来源。点不动的通知就是叫了也没用的提醒。
- 「清空」是把全部标为已读，**不删除**任何东西。
- 第一个真正的来源是**任务失败**：同一个任务一天只有一条，任务记录了失败原因就带上原因，并且能跳回那个任务。
- 通知设置里多了「发送测试通知」，用来验一次完整链路；它不代表任何真实事件。

### 「一天」只由一个地方算

日报生成时刻、任务排期、免打扰窗口、分析日界，现在都跟着你在设置里选的时区走，而且只由一个地方解析，
不再是几处各算各的。界面上显示的时刻带 `GMT±n` 后缀，不会再出现「按本地时间显示、标签却写着 UTC」。

### 代理

- 写错的代理地址在保存时就被拒绝，并说明原因，不再静默变成直连。
- 自检说的是「解析之后实际走了哪条路」，不再把你输入的字符串当成结论；解析成直连时不会显示成功。
- 目标站返回 401、403、404 时，提示说「目标站拒绝了这个请求」，不再报成代理的问题。
- 绕过规则只有一份实现，Chromium 与 WebSocket 两条出网路径行为一致。

### 缓存治理

刷新会真的重新巡检每个缓存，不再读内存里的旧值；同时点两次刷新会共用同一次巡检，结束后再重读。
巡检失败会如实标成失败，不拿旧值冒充。压缩指标改成「压缩前后记录体积的差」，不再拿整份记录体积当省下的量。

### 界面

空态、出错态、禁用态，纯图标按钮，状态词和右键菜单，现在各自只有一处实现；提示气泡可以用键盘聚焦，
并且固定在触发它的东西下方。状态文案把「没跑过」「还没」「正在」「失败」「不可用」分开，不再一个词承担两种处境。

### 默认值

两个首次启动的默认值改了，所以新装打开的样子不一样：

- 显示风格默认是**深色**，不再跟随系统。
- 代理模式默认是**跟随系统代理**，不再是不走代理，所以出站请求会先看系统代理的设置。

### 通道

通道的内部维护改成平台任务，设置页的任务列表里不再出现「审计清理」「投递重试」这类内部项；
它们的运行记录仍然可以在任务运行记录里查到。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，
   然后**右键（或 Control）点击应用 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；
   Windows 上运行安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
   如果 macOS 仍然拒绝，执行 `xattr -dr com.apple.quarantine /Applications/MacroBay.app` 再打开一次。
2. **切换时区可能让当天日报换个版次**：当天已经生成的版次不动，可能会按新时区另落一版。
3. **开盘去重记录会按 UTC 重落一次**，每个槽位最多补做一次分析。
4. **旧的分号分隔代理绕过规则会被归一化成逗号形态**：没有主机名的残片（例如 `:1`）会被丢弃；
   写法不受支持的条目（例如 `10.0.0.0/8`）原样保留，只有你真去改网络设置时才会被拒，并指名是哪几条。
5. **分析调用额度改成按线分额，总数变大**：数据线 60/日、15/时，日历 9/日、3/时，盘口 3 另计。
   相对早先的 12 次/天是放宽，不是收紧。
6. **通道的内部维护任务不再出现在设置页的任务列表里**，这是有意为之，不是任务丢了。
7. **如果你没有手动改过显示风格或代理设置**，升级后会用新的默认值（深色 / 跟随系统代理）；想保持原来的样子，请在设置里改回。

## 已知限制

- Windows 安装器能构建、产物内容也查过，但**安装后的运行态还没有在 Windows 真机上验收**：
  安装引导页、快捷方式、通知、任务栏分组都还没验过。
- 没有自动更新通道；Linux 未打包。
- 安装包品牌图由一份不在仓库里的本地脚本生成，只靠仓库重建不出来。
- Windows 上托盘图标由空图创建，实际不可见；「用其他应用打开」目前只支持 macOS。
