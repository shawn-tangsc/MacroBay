# MacroBay 0.4.2

What changed for the people using the app, and what to look at before you upgrade a copy you already
run. For what the app can and cannot do at all, see [Status and limitations](../status-and-limitations.md).

## Download

- macOS · Apple Silicon: `MacroBay-arm64.dmg`
- macOS · Intel: `MacroBay-x64.dmg`

**Intel build status.** The Intel build is `MacroBay-x64.dmg`: **it is built by the release workflow,
but it has not been verified on Intel hardware yet.** The Apple Silicon download link is unchanged,
and `latest-mac.yml` is produced only by the arm64 job.

The build is unsigned and not notarized, so the first launch still takes the two steps described in
the README.
