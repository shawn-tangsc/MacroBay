MacroBay 0.4.2 — 日报更可靠、设置不再丢、界面少说废话

✨ 新功能

• 采集策略 每个情报源可以单独设采集预设（手动／均衡／高频）和是否纳入情绪分析，改完即时保存；存不上会保留你刚选的值并提示重试。
• 说明性文字 正文只留字段名、当前值、控件；解释与范围收进旁边那颗「问号」里，悬停或键盘聚焦就能看。没用的解释直接删掉。

🔧 问题修复

• 黑屏 点「生成日报」会整窗黑屏：智能体待办面板从隐藏变成出现时钩子顺序变了，React 把整棵树卸掉。生成日报本身就是一次智能体任务，所以一按就崩。已修。
• 日报 模型不可用、被限流或没配 Key 时，这一期仍然发布事实层内容并说明原因；同一期混进另一种语言先重写一次，仍然混就整期不发；宏观栏读不到日历印「暂时读不到」而不是「没有」；过期那行说清用的哪一天数据；要闻标题与正文语言不一致时标「原文」；复制文本与正文一致；你正在看的那一期不会被跑完的别的期顶回去。
• 日历 顶部常驻说明收进问号；事件详情浮在日历之上，不再挤压月份列宽；详情新增「第一次落库」「实际公布值第一次拿到」两个时刻；空页面区分「来源没启用」与「确实没有事件」；某来源没有英文条目时明说。
• 设置 读不出设置文件时按默认设置启动，并在顶部给出坏文件副本路径与「重试读取」；「重置设置」单独放底部危险区。读不出来的文件不再被当成空的盖回去。
• 侧栏 会话列表只剩一个滚动条；会话名里不再出现内部编号。
• 数据 读不出来的记录一律保留原文件并留副本，涉及日报历史、历史判断、设置、日报 AI 设置、推送阈值、日历提醒；之前被藏起来的日报历史会重新出现；舆情库损坏不再整库重来。
• 推送 Telegram 连不上会自己重连，状态说清「正在重试」「已恢复」「已停止」；发送测试不再因为连点而连发。
• 时间与状态 带时区的时刻不再重复印偏移；一支数据缺失不再让整块消失，另一支标「未知」并给原因；数据格式不兼容时直接说「完全退出重开后恢复」，不再给一个点不动的重试按钮。

⚠️ 升级前

• 未签名、未公证：macOS 首次启动要右键「打开」，Windows 要在 SmartScreen 选「仍要运行」，每次更新都要重走。
