# MacroBay 0.4.5

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 下载

- macOS · Apple 芯片：`MacroBay-arm64.dmg`
- macOS · Intel：`MacroBay-x64.dmg`
- Windows：安装器随版本发布

**三个安装包都还没有在真机上跑过首次安装验收**：arm64、Intel 与 Windows。构件通过、随版本发布，
但没有一份首次安装的实际记录。

产物未签名、未公证，首次启动仍需按下面「升级前请先看」第 1 条放行。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，然后
   **右键（或 Control）点击 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；右键菜单里没有
   「打开」时（较新的 macOS 版本移除了它），去**系统设置 → 隐私与安全性**点「仍要打开」。Windows 上
   运行安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
2. **日历提醒命中的事件变了，这是有意改的。** 以前每个源各自标重要性：真正要紧的发布常被标成
   「中」，一些次要事件却标着「高」。这一版档位由应用按发布族自己判，默认的「只看高」命中的会是
   **CPI、非农、FOMC、主要央行利率决议** 这一档。如果你以前开过提醒、档位又留在默认值，升级后请
   先看一眼档位——以前会响的那些，有些以后不会再响。
3. **美国劳工统计局的官方日历仍然取不到（对方返回 403）**，自动同步保持停用；日历里已有的那批数据
   停在上一次成功同步。
4. **两项平台侧开关是前提（同上一版）。** Discord 要先在开发者后台为这个 bot 打开 **Message
   Content**；Slack 要在 App 侧开启 **Socket Mode**。这两项都在平台后台，不在应用里。

## 你会看到的变化

### 看板：国债收益率有了一条日频曲线

- **看板里多出一张「国债收益率 · 日频」卡**，左边是读数表、右边是曲线：五个期限（3M 到 30Y）、
  两条价差，以及 10 年期拆开看的实际利率与通胀补偿。
- **曲线有两种读法**：「收益率」看绝对水平，「起点归一」看相对窗口起点涨跌了多少个基点；另有几个
  不同长度的窗口可选。
- **背后的序列从一条扩到 19 条**（名义利率 11 档、实际利率 5 档、通胀预期 3 条），所以能回答「这波
  涨的是实际利率还是通胀预期」，而这在只有 10 年期一条数的时候答不出来。
- 数据是 FRED 日收盘，**可能滞后 1–2 个交易日**，卡上有这行说明。

### 看板：一张卡并排读「怕不怕」和「买下跌保护贵不贵」

- **新卡「恐惧与防跌溢价」**：仪表在中间，两侧各一张走势，下面单独一行写组合结论。
- **它只说局面，不给方向、也不给买卖点。**
- **两半口径不同，不能相加、也不能互相印证**：一半是全球加密情绪指数，另一半是 BTC 期权的防跌
  溢价，来自 Deribit 单所；两半的日期都是数据源自己的日期。
- **期权那半这一版还没有代理来源，卡上直接写「未接入」**——不是没有数据，是还没接上；不画线、也
  不是空态，接上以后再出数。
- **设置 → 情报源里能看见这两个源**（恐惧贪婪、期权偏斜）：能力、开关与状态都在，偏斜那半显示
  「未接入」。

### 看板：图更看得清，也更不容易误读

- **浅色主题下调色板换了**：原来五个颜色在白底上对比太弱，有几条线几乎看不见；现在五色都够清楚。
- **悬停浮层不再压住要读的那一列**：看最右边几天时，浮层翻到光标左侧。
- **持仓卡上的图加高了**：图画布用到了卡片能给的高度（以前只有一半高）。
- **卡片变窄时文字不再整行缩小**：图按容器的像素重画，字保持原来的大小。
- **持仓卡图上的爆仓牌子按方向分开**：多头、空头各一行、各带自己的颜色，不再并成一句「疑似爆仓 ×N」
  ——多头爆仓和空头爆仓是相反的市场含义。
- **资金费率图的时间轴刻度收紧了**：同一显示日的刻度只写时刻，五档不再叠成一片。
- **同起点收益率的横轴也不再每个刻度印一遍时区。**
- **跨资产判读缺一条腿时不再整条说「未定」**：改成按手上已有的数据说明能排除什么、还不能排除什么。
- **来源不可用行不再有「显示 / 隐藏」开关**：这两个开关撤掉了，改成一套固定规则——哪种来源会被
  显示、哪种不会，不用再自己拨。

### 资金面：日期按交易日算

- **「最新」「连续」两列现在读作「N 个交易日」**，周末和未定稿的日子不算进去。
- **表头那行 as-of 是数据自己最后一天**，不是今天；看到日期停在上一交易日是正常的。
- **ETF 那行同样按交易日对齐**，不会把「今天」当成数据日期。
- **某一格没启用时会说清是哪一格**：句子后面直接带源名，不用猜是哪一路没开。
- **重读失败不再让整张卡变成错误**：保留上一次的读数，并标成「已滞后」——数据没有丢，仍是上一次
  的读数；只有第一次就读不到时才如实报错。

### 日历：档位自己判，事件详情里能看解读

- **事件档位不再照抄来源**：来源几乎把每条都标成「中」，我们对不齐；这一版按发布族自己判，判不出
  的会标成未分级，不会被当成「高」也不会被当成「低」。
- **「AI 解读」进了经济日历事件页**：标题、正文，加一行「生成于 {时刻} · 依据：…」。它按档生成，
  **不是每条都有**：高档事件在实际值公布后自动生成，其余在第一次打开时才生成；还没公布实际值、或
  判不出档的事件没有解读。读不到已生成的那份时只写一句提示，加一个「重试」，点它重读本地，
  **不会再去问一次模型**。
- **同一份发布的同一期次只留一行**：以前「第二次估算」这类修订序号会被当成另一期，同一天出现两条。

### 舆情：一次能看更多

- **舆情列表一屏 30 条，滚到底再加载 30 条**（以前一屏 15 条、每次加载 15 条）。

### 通知中心

- **「看原文」这类动作现在真的画成按钮**：以前记录里写着动作、界面上点不到；点开交给浏览器。
- **只有一种语言的记录不再变成「有一条新通知」**：另一种语言界面下会退回能用的那一版，而不是一条
  没有正文的通知。
- **动作按钮的读屏名带上本条标题**：一屏几个「打开任务」时，读屏逐个 Tab 过去能分出是哪一条。

### 日报与引用

- **自动推送的海报出不来时，正文照发**：不会因为图没生成好而让当天少一条。
- **简报的引用列表不再一句话挂三条**：同一句只出现一次。

### 情报源与设置

- **原始记录有了保留期**：原文与元数据不再只增不减，过期自动清理；以前是磁盘一直涨。
- **宽表弹窗用全宽档，内容自己横向滚**：六列、带长指标码与网址的表不再被挤扁。

## 已知限制

- **arm64、Intel 与 Windows 三个安装包都没有在真机上完成首次安装验收。**
- **美元指数可能整段没有数据，这是套餐限制，不是坏了。** 续上提供这一路的套餐后，「最近 24 小时」
  那个窗口大约要一天才画满，缺口那段不会自动补回来。
- **美国劳工统计局的官方日历取不到**（对方 403），详见[状态与限制](../status-and-limitations.zh-CN.md)。
- **飞书与 QQ 这一版只发文字**：图片出站目前只在 Telegram、Slack、Discord 上开。
- **「恐惧与防跌溢价」的期权那半，代理接上之前恒为「未接入」**，不画线，也不参与组合结论。
- **日历里判不出档位的事件不会响**：它们标成未分级，既不当成「高」也不当成「低」，默认的「只看高」
  不会推它。
- **没有自动更新通道**：版本提示只告诉你「有新版本」，下载和安装仍要你自己来。
- **同一件事只提醒一次，升档不再补推**：一条新闻已经按「中」推过，后来升到「高」也不会再发一条。
