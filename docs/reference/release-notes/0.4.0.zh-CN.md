# MacroBay 0.4.0

这份说明写的是使用应用的人能感觉到的变化，以及升级已有副本前值得先看一眼的事。应用整体能用什么、
不能用什么，见[状态与限制](../status-and-limitations.zh-CN.md)。

## 升级前请先看这几条

1. **这个版本没有做代码签名，也没有做公证。** 首次启动要两步：macOS 上把应用拖进「应用程序」，然后
   **右键（或 Control）点击 → 打开**，再确认「打开」——直接双击会被 Gatekeeper 拦下；Windows 上运行
   安装器，在 SmartScreen 里选**更多信息 → 仍要运行**。**每次下载更新后都要重走这两步。**
2. **日报生成时刻现在能设到一天里任意半点**；你之前保存过的值保留不变。
3. **日报历史从「按天」改成「按期」。** 一天只有一期时看起来一样；一天多期时会出现多条，行内可切语言。
4. **日报生成完成会有一条桌面通知**，0.3.x 没有这一条；不想要就把「桌面提醒」这个总开关关掉，
   中心里的记录仍然会写。
5. **通知不再逐条勾选**：应用内提示与桌面提醒各一个总开关，另外情报页可以选择哪几条推到手机。
   中心里的旧记录保留。
6. **分析额度仍按线分额**，这一版没有改动数值。

## 你会看到的变化

### 日报：能按期出，一期也能中英各一版

- **生成时刻不再只限早上。** 以前只放得下一天里的少数几个槽位、基本等于「早上那一版」；现在从
  `00:00` 到 `23:30` 任意半点都能设，晚间那一期放得下了。默认仍是 `07:00`。
- **同一期只取一次数，中英各自成篇。** 两版说的是同一批数据、同一个截止时刻，不会一篇九点、一篇十点。
  某一语言没出来时，那一期会标成「不完整」并说清缺哪一版——**不会静默地少一篇**。
- **历史按「期」分组。** 以前按天翻，一天多期时看不出哪篇是哪次跑的；现在每期一条，行内可以切中英，
  还能看到每次尝试，失败的那次也在。
- **手动生成只允许今天往前 3 天**，再往前的重跑会被拒绝——每次都是一次模型调用，界面挡不住 bug。

### 通知：会叫醒你，但顺利的一天还是 0 条

- 平台 13 条、情报 8 条，共 **21 条事件**；每条归哪一档是定好的（中心、提示、桌面、通道），
  **不是逐条勾选**。应用内提示与桌面提醒各只有一个总开关；中心里的记录一直写，不受开关影响。
- **能推到手机的只有四条**：日报生成完成、模块信号、宏观事件、舆情强度中以上；这四条还要你在情报页
  里勾了才推。其余一律不出本机——失败类只到中心与桌面。
- **日报生成完成会有一条桌面通知**；应用内提示不发这一条，提醒走桌面。
- 舆情推到手机这一档**每天最多 5 条**，超出的只进中心，并在列表里写明今天还有几条没推。
- **通道投递**：把通知接到已接入的通道上，支持 Telegram、Slack、飞书、Discord、QQ；企业微信只是占位，
  运行时会一直失败。连续失败会停推并留一条可查的记录，恢复后再留一条。

### 面板上的规则有事时，AI 分析会自己重跑一次

- 以前只有宏观大事会让分析重跑；现在两条模块规则也会：**杠杆端持仓异常（疑似强平）** 和
  **ETF 三日净流出越线**。
- 分析正文会写清是哪条规则触发的、当时读数多少、对照的门槛、落在哪一档。
- **前两周只记账、不自动降档**：触发太频繁时不会偷偷抬高门槛，两周后按真实频次由产品决定。
- 利率路径、跨资产、舆情这三类**这版不接**：前两类对主要看 crypto 的人价值不够，第三类已有别的路径在说。

### 侧栏会告诉你「有新版本」，关于页能看到这一版改了什么

- 侧栏「设置」上有一个小点，**只有真的有新版本才亮**，点进「关于我们」就清，同一个版本只亮一次。
- 关于页里有当前版本、最新版本、一个「检查更新」按钮，以及**这一版更新的正文**：按 Markdown 读进来，
  标题、列表、代码块、行内代码各按原样子显示；认不出的行当普通文字——宁可难看，不许少字。
- 点下载入口会用默认浏览器打开项目的 Releases 页。应用**不会**在后台下载，也**不会**自动安装。
- 从源码起的开发版**不检查更新、零出网**；只有装出来的版本才查。

### 资金流卡片：柱顶只标三根，数字对得上了

- 柱顶只标三个：**最大流入、最大流出、最后一天**；同一天同时占其中两个时只标一次。
- 图下多了「展开逐日数据」，逐日逐行列出，每格带单位。
- 单位与口径各只有一处：图头写「百万美元」，柱顶与表格用同一个字串；列名与行名都补了范围；
  两句「不可相互核对」；日期标「按 UTC 日」。

### 起不来、门禁误报、文件写坏：这三类毛病修了

- **Windows 上启动就崩**（临时目录指向一个建不出来的位置，数据库开不了，窗口还没出来就退）：
  启动时先探一次可写，不行就改用自己的目录；并且这一步**在所有数据库打开之前**完成，任何漏走的调用点
  会立刻失败在源头，而不是等你打完包才发现。
- **门禁在 Windows 上误报**：三个按路径查基线的门禁都做了路径归一化，不再把每个文件都当成新增超限文件。
- **配置文件写到一半崩了就永久读不出来**：写入改成「先写临时文件再改名」，读到撕裂的文件会从备份恢复，
  并把原始字节留一份。
- **CI 第一次有了 Windows 作业**：类型检查、平台敏感的三批用例、三个按路径查基线的门禁。

## 已知限制

- **Windows 安装后的运行态仍然没有在真机上验收**：安装引导、快捷方式、通知、任务栏分组都还没验过。
  这一版新加的 Windows 作业仍是第一次跑，跑绿之前请把「Windows 能装」当成没验过。
- **企业微信通道只是占位**：运行时会永远返回失败。其余五家（Telegram、Slack、飞书、Discord、QQ）
  是真实实现。
- **通知的产品内配置抽屉本版不做**：通知设置仍在设置页里，但从产品页直接打开配置的抽屉还没有；
  这件事被并进「设置整体重新梳理」。
- **被挤掉的信号读者查不到入口**：一次分析的额度被更重要的信号占满时，那条被挤掉的信号目前没有任何
  地方能查到。
- **规则链有两条验收要等条件**：「结论必须点名模块」要等一次真实分析跑完才能核；「前两周只记账不降档」
  要等两周过完。
- **没有自动更新通道**；Linux 未打包。更新提示只告诉你「有新版本」，下载与安装都要你自己做。
- Windows 上托盘图标由空图创建，实际不可见；「用其他应用打开」目前只支持 macOS。
