# 常见问题

## 需要模型供应商账号吗？

需要。MacroBay 不内置模型，也不提供托管代理。请在 **设置 → 模型服务** 添加已启用的供应商和
API Key。

## 数据会离开本机吗？

应用数据留在本地 `userData` 目录。请求会通过平台网络适配器发往你配置的模型供应商和数据源。
没有 MacroBay 分析服务。

## 可以用哪些模型？

供应商暴露、且满足任务要求的模型都可以。普通聊天的兼容范围比智能体运行时更宽；智能体运行时要求
Claude Code 兼容的 Messages 路由。智能体模型选择器只显示满足运行时约束的模型。

## 为什么分析需要 `asOf` 时间？

因为结论必须说明当时可用的信息。没有边界时，历史查询可能混入后来的修订，产生当时根本不可能知道的
结果。

## 为什么有些工具需要审批？

读取本地文件、执行命令或改变状态的工具会影响机器。审批行会显示将运行什么。可以允许或拒绝；拒绝
会带原因终止。

## 为什么智能体反问我，而不是直接回答？

有些选择会改变分析，例如对比窗口或基准。结构化问题卡片会把答案作为数据返回运行时，而不是让模型
再解析一段自由文本。

## 渠道功能可用吗？

不可用。Telegram、Slack、Lark、Discord、QQ、WeChat 集成仍在平台代码里，但本版本没有开放；UI 和
测试一起禁用。

## 支持 Windows 或 Linux 吗？

macOS 是已验证的开发平台。Electron 代码理论上可以在其他平台运行，但 Windows、Linux 尚未做端到端
验证。请按实验性支持对待，并报告具体失败。

## 没有看板或实时数据能用吗？

可以启动应用并使用智能体界面，但市场情报面板需要配置来源凭据和数据。没有内置 demo 数据库。

## 分析是投资建议吗？

不是。它是决策辅助。输出描述证据、假设、条件和缺口，不是无条件的买入或卖出指令。

## 如何备份或迁移？

备份 Electron 的 `userData` 目录。它包含设置、会话、本地数据库和受操作系统钥匙串保护的凭据。
请把备份当作敏感数据。

## 如何报告 bug？

提供操作系统版本、是从源码还是安装包运行、UI 的完整错误，以及移除凭据和个人路径后的相关日志。
