# 状态与限制

MacroBay 当前版本是 `0.2.2`。本文说明现在能用什么，以及首个公开版本故意不包含什么。

## 可以从源码使用

- 桌面 shell 可以通过 `pnpm dev` 启动。
- 可以添加、启用模型供应商并保存 API Key。
- 可以为智能体和助手选择默认模型。
- 智能体会话可以运行，并加载内置的 `market-intelligence` 产品。
- 情报门户、看板、宏观日历、情报源配置和分析智能体都可以从产品内进入。
- 智能体的结构化提问和工具审批会在对话中渲染。
- 仓库可以通过 `pnpm typecheck`、`pnpm test`、`pnpm build`。

## 本版本没有开放

### 渠道集成

Telegram、Slack、Lark、Discord、QQ、WeChat 的平台代码仍在，但设置页和智能体运行时面板已隐藏，
渠道测试套件也从默认测试中排除。在 UI 和测试被明确恢复之前，请把渠道视为不可用。

### 打包安装程序

`pnpm build` 只生成 `out/` 下的 Electron bundle。macOS 的 `.dmg` 可以用 `pnpm dist:mac` 从源码
构建，但未签名、未公证，从网络下载的副本会被 Gatekeeper 拦截，需要用户手动放行。Windows 的打包
已配置，安装器既能由 CI 构建、也能在 Windows 11 x64 真机上构建产出，但安装后的运行态尚未验收；
Linux 尚未配置打包。也没有自动更新通道。
详见[打包](../development/packaging.zh-CN.md)。

### 示例数据

应用内置一个示例场景：录制自真实观测的**一周**（2026 年 10 月）——市场状态、同起点收益率、资金费率、
稳定币与 ETF 流向、两个月日历、重点舆情，以及三条带证据的已发布结论。

- **不内置数据库。** 场景是 JSON，运行中的应用只把它读进内存，绝不写入你的数据库、分析历史、
  情绪聚合或来源健康计数。
- **它是录制，不是行情源。** 场景时钟钉在录制收盘那一刻，横幅写明这一点，数据不会更新；
  退出示例即无痕（开关只在当前会话有效）。
- **实时面板仍需凭据。** 示例模式只回答看板的读取请求，不调用任何供应商，也不发起网络请求。
- 文档截图取自示例模式，不是真实数据源。

## 平台支持

- **macOS**：已开发和验证。
- **Windows / Linux**：Electron 代码理论上可以运行，但尚未做端到端验证。请按实验性支持对待，并报告
  具体失败。

## 模型兼容性

智能体运行时要求 Claude Code 兼容的模型路由。模型服务可以暴露不同协议；不是所有能用于普通聊天的
模型都能在智能体里选择。模型不可用时，智能体页会说明是供应商停用、缺少 API Key、模型未启用，还是
运行时协议不兼容。

限流、超时和临时网络故障不等于端点不兼容。应用会保留模型可选，并把兼容性标为“未验证”，而不是
直接隐藏。

## 数据与隐私限制

- 数据是本地存储，但不是整体加密。请保护操作系统账号和 `userData` 目录。
- 供应商凭据走平台密钥库；渲染层只拿到掩码预览。
- 备份和迁移由用户负责。参见[隐私与安全](../platform/privacy-and-security.zh-CN.md)。
- MIT 许可证只覆盖代码，不覆盖第三方数据。参见[数据与第三方服务](./data-disclaimer.zh-CN.md)。
- 产品不是托管服务，没有账号找回。

## 产品限制

- 市场情报是决策辅助，不是投资建议。
- 没有下单、组合管理或券商连接。
- 分析质量取决于用户配置的来源、凭据和数据。
- 来源缺失时会明确暴露缺口，不会静默替换。

## API 与配置稳定性

`0.2.2` 不承诺内部 API、数据库 schema 或设置结构的稳定性。升级前请备份 `userData`。在公开接口
稳定之前，产品 manifest 和平台契约可能在小版本之间变化。

## 报告问题

报告 bug 时请包含：

- 操作系统和版本；
- 应用是从源码启动还是安装包；
- UI 上的完整错误文本；
- 相关本地日志，且已移除凭据和个人路径。
