# 快速开始

从这里开始，按顺序完成：模型服务 → 默认模型 → 情报源 → 看板。

> MacroBay 是本地桌面应用。模型供应商和情报源都由你自己配置，项目不内置数据，也不内置 Key。

## 1. 设置模型服务

打开 **设置 → 模型服务**。

1. 添加一个供应商，或从列表里选择一个。
2. 填写 API Key，并启用该供应商。
3. 添加或启用一个聊天模型。
4. 选择**智能体默认模型**；如果使用助手页，也选择助手默认模型。
5. 点一次**连接检查**。

保存后，渲染层只会拿到 `hasApiKey` 和掩码预览。原始 Key 留在主进程和平台密钥库中。

如果页面提示 `provider-not-ready`，先检查供应商是否启用、Key 是否保存、模型是否启用。

## 2. 设置情报源

打开 **设置 → 情报源**。

1. 启用你能访问的情报源。
2. 需要凭据的来源，填写对应的 Key。
3. 没有特殊需要，先保持默认采集频率。

![配置情报源](../assets/screenshots/sources.png)

看板只会渲染已启用来源支撑的面板。来源缺失或关闭时，面板会显示明确缺口，不会用一个中性值偷偷补上。

情报源目录里混合了多种免费或低成本平台接入。按需启用即可；部分来源需要你自己的账号、API Key 或网络环境。
如果来源已经启用但面板一直为空，先检查网络和代理设置，再判断是不是来源本身不可用。

## 3. 打开看板

打开**情报门户**，选择**数字货币市场解读员**，点**打开看板**。

看板会把这几类信息放在一起：

- 宏观背景；
- 跨资产观察；
- 资金条件；
- 最新发布的分析。

## 4. 问分析智能体

从看板打开分析智能体，问一个具体问题，例如：

> 最近这组宏观数据变化了什么？会影响哪些资产？

有用的回答会把**事实**、**假设**、**条件**、**缺口**分开，并说明它使用的截止时间。

## 什么算跑通

- 看板显示的是数值，不是空占位。
- 每个读数都能打开对应的证据和来源。
- 智能体回答里能看出证据和截止时间。
- 后续修订不会偷偷改写之前的回答。

## 还没有 Key？先看示例

没有 API Key、也不联网时，仍然能看到整张桌子：在情报门户打开**示例模式**（或点「打开示例看板」），
看板与三条已发布结论会回放真实录制的一周。它有明确标注、不会更新、不写入任何东西；关掉就回到你自己的
（空的）数据。详见[示例数据](../reference/status-and-limitations.zh-CN.md#示例数据)。
