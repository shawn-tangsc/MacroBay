# MacroBay UI 规则（一页）

[English](./ui-rules.md) | [中文](./ui-rules.zh-CN.md)

> 一份给人查的规则：一处写一次。其余文档指到这里，不重复正文。

## 1. 一页速查表

| 场景 | 必须用 | 禁止写法 | 判据 |
|---|---|---|---|
| 图标触发 | `IconButton`（`sm` 22 / `md` 24，名必填） | 手写 `<button>`；26/28px | `iconButtonKeyGuard`、`iconGlyphVariantGuard` |
| 空态 / 错误 / 禁用 / 权限 | `StateView`（`state` + `reasonCode`） | 本地空态、本地错误段 | `stateViewCallSiteGuard`、`check:state-content-ternary` |
| 多行说明浮层 | `Popover`（悬停/聚焦开、点击钉住、Esc 回焦） | 手写浮层、直接用 antd `Popover` | `popoverCallSiteGuard`、`popoverLimitsGuard` |
| 一句话提示 | `Tooltip` | — | `tooltipCallSiteGuard` |
| 右键菜单 | `ContextMenu`（`items: {key,labelKey,disabled?,tone?}`） | `<button role="menuitem">`、可点 `<li>` | **人看** |
| 状态词 | `StatusPill`（闭集 tone） | 手写药丸、字着色 | `statusPillKeyGuard` |
| 加载 | `LoadingState` / `LoadingSpinner` | 本地转圈、CSS 旋转、antd `Spin`、`加载中…` | `loadingStandard` |
| 可折叠分组头行 | 平台 `CollapsibleGroup`：**壳持有行与箭头，内容归作者** | 自绘箭头、自接整行点击、头行里放可聚焦元素 | `CollapsibleGroup` 头行守卫（使用处） |
| 标签页 | 平台 `Tabs`；**`WorkspaceTabStrip` 为当前唯一**登记例外（`AgentPortal`、`ModelServiceModelDrawer` 都不是） | 第三份自绘 Tab | `check-tab-role` |
| 分段 / 单选 | `Segmented` / `Select`（闭集） | 一行混两种控件 | **人看** |
| 开关 | antd `Switch` | 手写 `role="switch"` | **人看** |
| 抽屉 / 弹窗头动作 | 头的 `actions` 槽（距关闭键 12，一头一个） | 用产品 CSS 撑开标题行 | **人看**（有组件用例，无全仓守卫） |
| 按钮五档 | 主 / 次 / 图标 / 行内文字 / 危险，一个动作一档 | 自绘胶囊、28px 图标钮、危险只悬停变红 | **人看** |
| 行内文字动作（句子里、提示条里、状态条里的「重试 / 改短导读 / 展开明细」） | `<Button type="text" size="small" className="text-action">` | `type="link"`（走 antd `colorLink`，不在 token 里，会冒出第二个交互色）；手写 `<button>`；在调用点按 antd 默认值写 `height/padding/font-size` | **人看**：`type="link"` 只减不增（2026-11-12 基线 **12 处 / 8 个文件**，待清）；清到 0 之后「出现即退回」 |
| 说明性文字 | 该行/该组标题旁的 ⓘ（`IconButton` + `Popover`），默认收起 | 写成正文的一句、半句、括号补充、破折号补充 | `check:body-prose` |
| 卡片级动作 | **放在卡片标题行右侧**：只要这张卡依赖的任一数据源**未配置或读不到**，就在标题行给一颗（启用数据 / 重试）；卡内只说明缺哪一格 | 卡内再放同一颗动作；同屏同一动作两处入口 | **人看**（判据见下） |
| 必须看见的小字（11px `--font-meta` 及以上） | `--text` / `--text-secondary`；层级靠字重或位置 | 用 `--muted` 承载读者必须看见的信息 | **人看**：与它**实际所在底色**（牌底、卡底）的实测对比度 ≥ **4.5:1**（量，不靠看） |

**禁用状态的原因：先问「看得见吗」（2026-11-20 收窄，用户点名删掉那句废话）。** 两条判据：

- **读者看一眼就知道为什么点不了 → 不写句子。** 禁用由可见状态承担即可：按钮上的转圈、列表里那条「进行中」、以及控件自己的 `aria-busy`——这三样已经是证据，再写一句「正在跑，跑完再试」就是把同一件事说第二遍。
- **看不出来 → 必须写**，走 `DisabledHint`（可见文字 + `aria-describedby`）：无权限、来源未配置、额度用完这类，读者从界面上推不出来。

判据：禁用态渲染后，**要么**旁边有原因句，**要么**有承担原因的可见状态（进行中条目 / 转圈 / `aria-busy`）；两者都没有才算缺陷。反例：`analysisInFlight` 那条「正在解析，完成后再试」已被删除——它旁边就是转圈按钮和列表里的进行中条目。

**卡片级动作只放标题行（2026-11-11）**：一张卡若依赖的任何一个数据源未配置或读不到，动作（启用数据 / 重试）放在**卡片标题行右侧**，卡内只保留说明缺哪一格，不再重复放同一颗动作；**同屏同一动作只允许一处入口**。
判据：有任一源未配 → 标题行有动作；全部配好 → 无动作；同屏同类动作数 = 1。
**例外**：整卡依赖的源**一个都没配置**时，动作移到内容区遮罩内居中，标题行动作不出现；卡内仍只允许一处入口。判据：全未配置时卡内可聚焦元素恰 1 个，且标题行无动作。

**「行内文字动作」禁的是自己写外观，不是「不能用这个类」（2026-11-12，界面设计定稿）。** `.text-action`（`platform/ui/styles/textAction.css`）本来就设计成挂在 antd `Button` 上：它给 `--accent`、下划线、`2px` 焦点环、禁用态（`--muted` + 无下划线）；调用点不需要再补任何尺寸或颜色。`dailyBriefing.css` 里那三条压 antd 默认值的规则就是反例。
**例外要登记**：不是「动作」的链接（下载文件的 `<a download>`、跳外部的 `<a href>`）走锚点，不适用这条；出现了按「组件表达不了」写清为什么。

## 2. 字号与字重

字重只有四档：**400 / 500 / 600 / 650**。其余值（500 以上非档位、620、680、700、750）一律并回。

| 用途 | 字号 / 行高 / 字重 | token |
|---|---|---|
| 行标题（会话名、事件名） | 12 / 1.5 / 500 | `--font-body` / `--line-body` |
| 行 meta（时间、来源、计数） | 11 / 1.5 / 400 + `tabular-nums` | `--font-meta` / `--line-meta` |
| 正文句 | 12 / 1.5 / 400 | `--font-body` / `--line-body` |
| 分组标题（今天 / 更早） | 11.5 / 1.6 / 600 | `--font-section` / `--line-section` |
| 阅读注释 | 11.5 / 1.6 / 400 | 同上 |
| 页面主名（一屏的主角名，如详情页标题） | 16 / 1.35 / 650 / `--text-strong` | **缺**（字面量 16；只用于一屏的主角名，不用于区块标题、不用于行、**不用于卡头**——配置抽屉的卡头页名已撤 `3403c15`） |
| 卡片 / 区块标题 | 13 / 1.4 / 650 | `--font-card-title` / `--line-card-title` |
| 设置行标签 | 13 / 1.4 / 400 | **缺** |
| 表内数字、坐标轴 | 11 / 1 / 400 或 600 + `tabular-nums` | **缺** |
| 数据展示（读数、大数字，如仪表中心分数） | 24 / 30 / 42 / 600 + `tabular-nums` | `--font-metric-sm` / `--font-metric-md` / `--font-metric-lg` |

- 行标题必须比分组标题**轻一档**（500 对 600）：内容比结构轻。
- **可折叠分组的头行与分组标题同一档**：`--font-section` / `--line-section` / 600 / `--muted-strong`。平台 `CollapsibleGroup` 落地后必须用同一个值，否则壳与页面又是两套。
- 卡标题 13 已有 token（`--font-card-title` / `--line-card-title`，2026-11-22 补）：新代码只许引用，不许再写字面量。
- **数据展示字号是独立一支**（24 / 30 / 42），不进正文字阶：仪表中心分数用 `--font-metric-sm`（2026-11-22 起），不用 `body × 2` 这类推算值；出处 `docs-private/05-desktop/ui-audit/ui-component-baseline.md:23`。
- **落进页面只许等值替换**（12 / 11 / 11.5 换成引用，视觉零变化）；把 10 / 10.5 / 9.5 抬到 11 是**可见变化**，单独一笔并带改前改后对比。
- **禁止用 10 / 10.5 / 9.5 就近凑**。

## 3. 间距

| 规则 | 值 |
|---|---|
| 只许用主档 | **4 / 6 / 8 / 10 / 12 / 16** |
| 列表行 | 行高 44（单行）/ 60（两行）；**日志与消息流等密集流 32**，左右 12，标题与 meta 相距 8 |
| 页面外框边距 | **24**（只用于页面级外框；**不用于行内、不用于组间，也不用于卡内距**——抽屉内容卡用 16） |
| 新增 | 非主档值出现即不合格；存量按清单并，不全仓重排 |
| 两列行（字段区 + 右侧控件） | 左字段区 **`flex: 1; min-width: 0`**，右控件 **`flex: none`** |

## 4. 颜色

**判据**：左字段区没有 `min-width: 0` 时，长串会被挤成竖排／一字一格——`ProviderDetail` 那处 403 串就是这么坏的。两列行一律按上表写，别等下一屏再犯一次。

| token | 用途 | 禁止 |
|---|---|---|
| `--text` | 正文、标签、值 | — |
| `--text-strong` | 读数里的强调 | 整段正文 |
| `--muted` | meta、单位、时刻 | 要读者行动的信息 |
| `--muted-strong` | 次级标题 | 正文 |
| `--border` / `--border-strong` | 分隔线、卡边 | 当文字色 |
| `--surface*` | 底色 | 当文字色 |
| `--accent` | 唯一交互色：链接、焦点环、主按钮底 | **警示、错误、「重要」** |
| `--danger` | 破坏性动作、失败文字 | 装饰、强调 |
| `--warning` | 注意但不是故障 | 错误 |
| `--caution` | 陈旧 / 降级（第一语义），以及时钟环类别浮层里的**预期值**（第二语义，2026-11-24 登记） | 当通用的「重要」；作为「这是预期」的唯一承载 | **人看**：把颜色去掉，句子仍然写着「预期」/`expected`；两套主题对浮层底色 ≥ 4.5:1 |
| `--success` | 已确认 / 健康 | 「没有数据」 |
| `--info` | **方向**：相对预期的「低于」（预期差为负）的描边/文字；亮色主题用描边不实底 | **好坏**判断、把「高于预期」也说成正面 |
| `--mi-dashboard-*` | 看板语义色（正负、警示、线色） | 跨模块借用 |

**必须看见的小字不用 `--muted`（2026-11-21，时钟牌实测 3.82:1 引出）。** `--muted` 只给可看可不看的 meta；读者必须抓到的小字用 `--text` 或 `--text-secondary`，层级靠字重或位置体现，不靠把它压暗。判据：小字与**它实际所在底色**（牌底、卡底）的对比度 ≥ 4.5:1，按那块底色上的真实色值算，不许目测。反例：时钟牌上的「4 天后」压在 `#293958` 上、用 `--muted`，实测 **3.82:1**；改成 `--text` 650 后 **9.50:1**，同时把值退到 `--text-secondary` 500，**6.29:1**。

**`--caution` 有两个语义，第二个是登记的（2026-11-24）。** 第一语义：陈旧或降级，「看一眼这里」。第二语义：时钟环类别浮层里的**预期值**——那张卡的图里本来就用同一个橘做预期标记，所以在那张卡里读法一致。三条约束防止它长出第三语义：① **颜色只做强化，不做标签**——句子自己写着「预期」/`expected`（`{name} 预期 {value} · {when}`），所以黑白截图、色觉障碍、读屏三种场景都拿得到这层意思；② 故障绝不用它顶替 `--danger` / `--warning`；③ 对比度按两套主题对浮层自己的底色（`colorBgElevated`）实测——**深 5.64:1、浅 4.59:1**，`tokens.test.ts` 里有棘轮，把 `--caution` 调浅就红。**不要**改成更深的橘：图里那支预期标记用的是同一个 token，另起一个橘会拆散这层呼应。

门禁三道，各自留一个洞：

| 门禁 | 挡 | 不挡 |
|---|---|---|
| `check:hex-color` | 硬写十六进制色 | **用错色**（accent 画警示） |
| `check:undefined-token` | `var(--x)` 未定义 | 用了一个「定义过但不该用」的 token |
| `check:danger-color` | 新增的 `color: var(--danger)`（基线只减不增） | `background` / `border-color` 用 danger、拿别的红替代它 |

因此：**用错色、非前台 danger，目前没有门禁**，靠审核；审核清单要单列这两条。

## 5. 禁止清单

- 手写 `<button>` 代替 `IconButton`。
- 使用非档位字重（620 / 680 / 700 / 750）。
- 硬写 px 字号代替字号档。
- 手写 `role="switch"`。
- 自绘 `role="tab"`（除已登记的工作区 Tab 条——**这是当前唯一的例外**，登记在 `scripts/check-tab-role.mts`；`ModelServiceModelDrawer` 不是第二个：它那笔 `role="switch"` 欠账已随源码合规删除，页签从来没有它的事）。
- 手拼 `YYYY/M/D` 时间。
- 同一行重复同一事实（典型：标题与行尾各印一次时间）。
- 在正文里写说明性文字（范围解释、实现细节、安慰性说明——「只影响…」「不会影响…」都算）。
- 给**不可恢复的失败**（官方源 403、来自别的版本的数据格式）配重试按钮——那是假控件；这类只给「不可用 + 原因」，并说清「不知道什么时候会好」。

## 6. 动画

**旋转只归加载——只有一个具名例外。** 全仓默认只有 `loadingState.css` 能转（转圈＝正在加载）。唯一例外是时钟卡那条装饰性流光，必须**按名字登记**，不许按「动画」这个类别模糊放行：

| | |
|---|---|
| 例外位置 | `products/market-intelligence/desktop/pages/intelligence/clockCard.css` 的 `.mi-clock__orbit`（只有它，别的选择器不算） |
| 形式 | 扇面渐变光自转：`animation: mi-clock-spin 8s linear infinite`，`@keyframes { to { transform: rotate(360deg) } }`，`transform-origin: 156px 153px` |
| 为什么不会和加载态混 | 加载时整块被替换成 `loadingState`，两者**不同屏**；它也不是进度指示，读不读都在那儿 |
| 减少动态效果 | `animation: none`，**光必须仍然可见**（静止在原位）。**禁止 `display: none`**——2026-11-15 就是把它藏了没告诉人，用户以为坏了，查了两小时 |

**判据**：`loadingStandard` 读的方向是「除这一处具名例外，任何 `rotate` 动画都红」。把例外之外的任何元素加上 `rotate`，守卫必须红；把例外这处删掉，时钟卡的流光用例必须红。

**视觉变化必须告知用户。** 停掉、藏掉、替换任何用户能看见的动画或装饰之前，先在群里说一句「哪一处、变成什么样、为什么」。静默的视觉变化和静默删功能一样，都属于「用户以为坏了但没人知道」。
